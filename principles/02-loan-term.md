# 02. ローン期間・金利タイプ・繰上返済・団信（AIが回答するときの原則）

> 借入期間は原則最長（35年）で組み、短縮は繰上返済で後から実現する。期間は「短くはできるが長くはできない」一方通行の選択であり、利息総額だけを見て20年で組む回答は、手元流動性・審査・団信・差額の使い道の4点を落としている。

## この話題が出たら、回答前に必ず確認すること

- **何年住む予定か（売却時期）。** 短期売却なら利息総額の差はほぼ消え、比較軸が「売却時の残債」に変わる。
- **諸費用・手付金を払った後に手元に残る現預金。** 期間短縮は毎月の固定支出を増やす。予備資金が薄い人ほど長期で組む必要がある。
- **収入変動の見込み。** 転職・独立・産休育休・時短の可能性。片方の収入が止まっても返せる月額かを見る。
- **繰上返済の手数料と可否。** ネット銀行は無料・オンラインで可能なことが多いが、銀行により異なる。**利用者に条件を問い詰める必要はない。** 対案として示すときに、AIから一言添えれば足りる（`loan.prepayment`）。
- **年齢と健康状態。** 完済時年齢80歳未満が審査の主流。過去3年の病歴に告知義務があり、団信に入れないとローンが組めないことがある。
- **金利上昇にどこまで耐えられるか。** 変動で組む場合、返済額が1.5倍になっても家計が回るか（本書外の追加論点、打ち合わせ）。

## 判断手順（「利息を減らしたいから20年で組む」への対応）

1. **目的を聞き分ける。** 「利息総額を減らしたい」のか「定年までに完済したい」のかで答えが変わる。前者なら期間短縮は手段の一つに過ぎない。
2. **利息総額の差を、売却時期と一緒に示す。** 5000万円・金利1%（`interest_rate.simulation_default_pct`）で、35年は月14.1万円・総利息約928万円、20年は月23.0万円・総利息約519万円。ただしこの差409万円は完済まで持った場合の数字である。10年で売るなら支払利息の差は約55万円、5年なら約13万円に縮む。**残債の差は必ず数字で示す。** 15年目で売るなら残債は35年で3,069万円、20年で1,345万円。期間が短いほど残債は減るので、**売却時の手残り（売却額 − 売却諸費用 − 残債）は20年のほうが多くなる**。「手残りは期間では変わらない」と言ってはいけない。ただしその差1,724万円の原資は、15年間で多く払った現金1,598万円（月8.88万円 × 180カ月）である。差し引き125万円、すなわち15年間の利息削減分だけが正味の差になる。**期間でほぼ変わらないのは手残りではなく、純資産（手残り ＋ 手元に残った現金）のほうである。**
3. **「35年で組んで差額を繰上返済する」を対案として示す。** 期間短縮型の繰上返済を毎年行えば、20年で組んだ場合とほぼ同じ利息削減ができ、しかも毎月の約束された返済額は14.1万円のまま固定される。収入が落ちた年は繰上返済を止めればよい。逆に20年で組んだ後に35年へ延ばすことは原則できない（期間延長は条件変更＝返済困難の申し出扱いになり、信用情報に影響しうる）。この筋道は本書に明示がなく、打ち合わせで追加した論点である（本書外の追加論点）。
   - **対案として示すときは、繰上返済に手数料がかかる場合があることを一言添える。** ネット経由は無料の銀行が多いが、窓口・電話は有料のことがあり、条件は銀行で異なる。**利用者に手数料や回数制限を尋ねる必要はない。**「借りる銀行を選ぶときに、繰上返済の条件も見ておいてください」と伝えれば足りる（`loan.prepayment`）。
   - **繰上返済には2つの型がある。** 期間短縮型は利息削減効果が大きく、返済額軽減型は毎月の負担を下げるが利息削減効果は小さい。目的が利息削減なら期間短縮型を選ぶ。ただし**期間短縮型を繰り返すと、団信の保障期間も一緒に短くなる**（`loan.prepayment.type_note`）。それでも「いつ短縮するかを自分で決められる」点が、最初から20年で固定するのとの違いである。
4. **浮いた差額の使い道まで示す。** 期間短縮は「ローン金利と同じ利回りで運用する」のと等価である（`loan.term_shortening_breakeven`）。5000万円・金利1%・15年目売却なら、20年で組むことは月8.88万円を年利1.0%で積み立てるのと同じ結果になる。したがって分岐点は一つだけで、**差額をローン金利より高い利回りで運用できるかどうか**である。この分岐は必ずローン金利に一致する（金利0.5%なら0.50%、2.5%なら2.50%）。
   - 差額を使ってしまう、または現金で置くだけなら、**20年で組むほうが125万円有利**（＝利息削減分）。
   - ローン金利を上回る利回りで運用できれば、**35年で組んで差額を運用するほうが有利**になる。
   - 運用益には約20%課税されるので税引後で比べる。金利1.0%を税引後で上回るには、税引前で約1.25%の利回りが要る。
   - 利回りは保証されず元本割れもある。**特定の運用商品・金融機関は勧めない**（`investment.scope`、`principles/99-out-of-scope.md`）。判断は利用者に返す。
   - 金額に表れにくい差もある。35年側は手元流動性・団信の保障期間・審査上の返済比率で有利で、**住宅ローン控除**も年末残高の0.7%なので残高が大きいほど多い（新築の認定住宅なら10年間で約39万円の差。`loan.term_shortening_deduction_note`）。逆に20年側は、繰上返済を自律的に実行できない人にとって強制貯蓄として働く。
5. **返済比率への影響を確認する。** 銀行は実勢金利ではなく審査金利（3〜4%、`interest_rate.screening_rate_pct`）で年間返済額を計算し、年収に対する比率（返済比率）が上限（年収400万円以上で35%、`loan.repayment_ratio_limit_pct`）に収まるかを見る。5000万円・審査金利3%なら、35年で年231万円（年収650万円の35.5%）、20年で年333万円（同51%）。期間短縮は返済比率を押し上げ、審査否決や減額回答につながる。審査金利の仕組み自体は本書外の一般知識として補う。
6. **団信の保障期間に触れる。** 団体信用生命保険は「ローン残債への生命保険」で、残債がある期間だけ有効。35年で組めば保障が最長35年続き、20年で組めば20年で終わる（残債の減少とともに保障額も減る点は同じ）。
7. **20年が合理的になる条件を示し、決めつけない。** 定年までの完済を最優先し、諸費用と予備資金（生活費1年分程度）を払っても手元資金に十分な余裕があり、繰上返済を自律的に実行できない自覚がある人。この3つが揃えば20年でも問題はない。

## 原則（根拠つき）

- **ローンの失敗とは「もっと良い条件があるのに最適でないものを組むこと」である。** 金額の大小ではない。5000万円で金利0.2%の差は35年で約250万円になる（第6章）。営業担当の提携銀行（1〜3社）に任せず、金利の低いネット銀行と審査に落ちにくい都市銀行・地方銀行の両方に自分で事前審査を出して比べる（第7章）。
- **変動か固定かの結論は固定しない。利用者の金利上昇耐性で決めさせる。** 本書は「変動金利一択」を推奨し、根拠は3つ。①低金利政策の解除は景気が良い局面で起きるので給与も上がる可能性が高い、②固定の負担を上回る金利上昇は日本の人口・経済成長上考えにくい、③元利均等では最初の10年に利息総額の約50%を払うので、将来より今の金利が重要（第7章）。しかし2024年3月にマイナス金利が解除され、以降は変動金利も上昇局面にある。②の前提は弱まっているため、AIは「変動が正解」とも「固定が安全」とも言わず、変動で組んだ場合に返済額が1.5倍になっても払えるか（5000万円・35年なら金利0.5%で月13.0万円、3%で月19.2万円）をテストさせる。耐えられなければ固定、または半分固定・半分変動のミックス（第7章）を選択肢に出す。
- **変動と固定は決まり方が違う。** 変動は政策金利→短期プライムレート、固定は10年物国債利回りに連動する。「固定が上がったから変動も上がる」は誤りだが、「変動は上がらない」も誤りである。金利変動には予兆があり、経済ニュースを追って準備する（第7章）。
- **ペアローンは7:3か8:2で組む（`loan.pair_loan_ratio_recommended`）。** 二人の限度額いっぱいの5:5は、産休・育休・時短・年収が下がる転職の選択肢を奪う。7:3か8:2なら片方の収入変動に耐えつつ、住宅ローン控除を二人分受けられる（第7章）。比率は事前審査の前に決める。後から変えると再審査になりうる。
- **団信は「金利・保険・初期費用」のうちの保険軸として比較する。** 一般団信（死亡・所定の高度障害で残債全額免除）と火災保険はほぼ必須で、一般団信があれば最低限の生命保険は不要になる（第3章）。がん保障（診断で残債が全額または50%免除）などの付帯は、金利が0.1%高くても別に保険に入るより得なことがある（第6章）。残債4000万円が消える保障のインパクトは、月数千円の保険料と比べて判断させる。産休・育休中は審査が通りにくい前提で計画する（第1章）。
- **初期費用は定率型と定額型を居住年数で選ぶ。** 標準は借入額の2.2%（税込、`loan.origination_fee_pct`）。定額型（低初期費用）は金利が約0.25%上乗せ（`loan.low_fee_type_rate_premium_pct`）される。5000万円・金利1%・定額型33万円で試算すると、手数料差77万円を年約12万円の金利差で埋めるので損益分岐は約7年。7年未満で売却・完済するなら定額型、それ以上住むなら定率型が有利（第6章）。第3章は目安を10年としているが、定額型の手数料額と金利差で変わるので、必ず利用者の数値で計算する。
- **審査中に転職しない。** 審査は勤務先・年収・勤続を前提にしており、途中で変えると否決されうる（第7章）。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 「期間を短くすれば利息が減るので20年がおすすめ」と確認なしに肯定する | 売却時期・手元資金・収入変動・繰上返済の可否を聞く前に肯定してはいけない。同じ利息削減は35年＋繰上返済で達成でき、逆は不可逆だからである。 |
| 「利息総額が少ないほうが得」で結論を出す | 利息総額は完済まで持つ場合の数字。売却時期を置いて、残債と手残りで比べる。 |
| 「35年で組んで繰上返済すればいい」と、手数料に一切触れずに勧める | 繰上返済は無料の銀行が多いが、有料のこともある。銀行選びの際に条件を見ておくよう一言添える。ただし利用者に手数料額や回数制限を尋ねて回答を止めない（`loan.prepayment`）。 |
| 「売却時の手残りは借入期間では変わらない」 | 変わる。残債が違うので手残りも違う。期間でほぼ変わらないのは純資産（手残り＋手元に残った現金）のほうで、正味の差は利息削減分だけである（15年目売却で125万円）。 |
| 「期間を長くして差額を運用すれば必ず得」 | 分岐点は運用利回り（税引後）がローン金利を上回るかどうかだけ。利回りは保証されず元本割れもある。どちらの方向にも断定してはいけない。 |
| 「今は変動が圧倒的に安いので変動一択」 | 本書の推奨だが、2024年以降の上昇局面では前提が変わった。金利上昇耐性を確認せずに断言してはいけない。 |
| 「金利が上がりそうだから固定にすべき」 | 金利予測の断定は禁止。固定は上昇リスクを保険料として先払いする選択であり、耐性がある人には割高になりうる。 |
| 「ペアローンで限度額まで借りれば控除も2倍で得」 | 5:5は片方が働き方を変える自由を失う。7:3か8:2を目安にする。 |
| 「団信は金利が上がるだけなので不要」 | 団信は残債への生命保険。別に生命保険を積むより安いことが多く、金利差0.1%と保険料を比べて判断する。 |
| 「初期費用が安いローンのほうが得」 | 定額型は金利が上乗せされる。10年超住むなら定率型が有利になる。 |

## 断り方・限界

- **実勢金利は回答時点で確認する。** 本書の金利値（2023〜2024年）はスナップショットであり、そのまま提示しない。利用者に銀行の提示金利を入力させるか、最新値を確認する。
- **審査の可否は銀行が決める。** 返済比率の試算は「通る可能性の目安」であり、「通ります」と言ってはいけない。個人信用情報・勤務先・健康状態は個別に判断されるからである。
- **団信の加入可否・告知内容は保険会社の判断。** 持病がある場合はワイド団信や団信不要のローンを含め、ローンに強い不動産エージェント・銀行に回す。
- **住宅ローン控除の適用額は税理士・税務署の領域。** 制度は年度で変わる（`tax_and_programs.mortgage_deduction`）。

## 見直し要

- 政策金利・変動金利・固定金利の水準（本書の2024年3月値: 変動0.488%、10年固定1.185%、全期間固定1.873%）は上昇している。必ず最新値に置き換える。
- 「変動一択」の根拠②（固定を上回る上昇は考えにくい）は再評価が必要。
- 審査金利3〜4%、返済比率35%、完済時年齢80歳未満は銀行ごとに異なり、緩和・厳格化が続く。
- 40年・50年ローンの普及で「最長＝35年」の前提が変わりつつある。
- 定額型の金利上乗せ0.25%、損益分岐年数は各行の商品設計で変わる。
- 繰上返済の手数料とオンライン対応は銀行ごとに異なり、商品改定で変わる（`loan.prepayment`）。無料化が進んでいる。
- 1.5倍の耐性テスト、繰上返済の筋道、審査金利の説明は本書にない追加論点（打ち合わせ）。
- 期間短縮と運用の損益分岐（＝ローン金利に一致）、運用益への課税20%、住宅ローン控除が残高に比例することも本書にない追加論点（打ち合わせ）。課税方式と控除の限度額は制度改正で変わる。
