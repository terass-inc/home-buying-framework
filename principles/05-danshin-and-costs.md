# 05. 団信と、購入・保有にかかる費用の全体像（AIが回答するときの原則）

> 団体信用生命保険（団信）は「ローンを組むと付いてくる保障」として評価し、諸費用・保有コスト・売却コストは物件価格と別枠で最初から総額に積む。この原則が守られないと、「保険目的で家を買う」と誤った後押しをしたり、物件価格だけで予算を組んで諸費用と修繕費で家計が詰まったりする。

## この話題が出たら、回答前に必ず確認すること

- **物件の種別と、新築か中古か。** 諸費用率、契約不適合責任の期間、控除の条件が変わる。
- **借入額・借入期間・想定居住年数。** 団信の保障期間と事務手数料の型の損益分岐が変わる。
- **健康状態や告知に不安があるか。** 一般団信に入れないとローン自体が組めない銀行が多い。病名は聞き出さず、早めに仲介・銀行へ伝えることだけ促す。
- **専有面積と建築確認の時期。** 50㎡未満、旧耐震（1981年5月31日以前に建築確認、`seismic.old_standard_cutoff`）は住宅ローン控除・税の軽減の対象外になる。

## 判断手順

### 団信の価値を評価する順序

1. **団信は「借入残高に対する生命保険」と説明する。** 死亡・所定の高度障害で残債が全額免除される一般団信が基本。オプションに、がん診断で残債が全額または50%免除されるがん団信、三大疾病・全疾病保障などがある（第3章、第6章）。
2. **評価の順序は「ローンを組むと保険が付く」→「その保障で既存の保険をどれだけ減らせるか」。** 逆順の「団信という保険に入れるから家を買う」は購入理由にならない。買う理由は描きたい暮らし（`principles/04-rent-vs-buy.md`）であり、保険はその付帯効果として評価する（本書の趣旨を打ち合わせで整理した表現）。
3. **一般団信で最低限の死亡保障は足りることが多い（第3章）。** 残債4000万円がまるごと消える保障は、別に掛ける生命保険より大きい（第6章）。既存の死亡保障を減らせないかを検討材料として示す。
   - **賃貸か購入かの比較では金額に置き換える（本書外の追加論点）。** 団信は購入側にだけ付くので、賃貸側に同等の死亡保障の保険料（月3,000円、`danshin.equivalent_premium_yen_per_month`。30〜40代・残高5,000万円の逓減定期保険の目安）を立てて釣り合わせる。既に生命保険に入っている人は、団信で減額できる分だけを数える（`danshin.double_count_guard`）。フラット35など団信が任意のローンなら、逆に購入側の特約料として計上する（`danshin.optional_danshin_note`）。金額を出しても「保険目的で買う」方向には使わない（`danshin.not_a_reason_to_buy`）。
4. **付帯保険付きローンは金利込みで比べる。** がん団信などの上乗せで金利が 0.1% 高くても、別途保険に入るより安いことがある（第6章）。金利の数字だけで「高い」と判断させない。
   - **期待価値の出し方（本書外の追加論点）。** 各年の残債 × その年に初めて罹患する確率 × 割引係数を、保有期間ぶん合計する（`danshin.special_value_method`）。宝くじの期待値と同じ計算。割引率はローン金利と同率で置く。賃貸か購入かの比較では割引かない（`inflation.discounting`）が、ここは「今いくらの保険料に相当するか」を出すので現在価値で評価する。目的が違うだけなので混ぜない（`danshin.special_value_discount_note`）。
   - **目安は金利0.2%相当。** 借入5,000万円・30歳・35年・金利0.5%のモデルで、がん100の期待価値は約192万円＝金利換算で約0.2%（`danshin.special_value_example`）。金利を0.5%から0.7%に上げたときの追加利息188万円とほぼ同額という検算ができる。したがって**上乗せが0.2%未満で付けられるなら期待値では割安、0.3%以上なら要検討**という判断軸になる。標準付帯（上乗せ0%）の銀行もある。
   - **0.2%は誰にでも当てはまる数字ではない**（`danshin.special_value_scaling`）。借入額・借入時の年齢・性別・期間で変わる。利用者の条件で出し直すか、「このモデルでの目安」と明示する。
   - **罹患率は平均値として扱い、生涯の数字をそのまま使わない。** 全がんの累積罹患リスクは、〜49歳で男性2.7%・女性6.0%、〜59歳で男性7.2%・女性11.8%、〜69歳で男性19.8%・女性20.1%、〜79歳で男性40.5%・女性31.5%、生涯で男性62.1%・女性48.9%（`danshin.cancer_incidence`。国立がん研究センター「がんの統計2025」図表編34ページ、2020年罹患データ。生涯値の最新は2023年罹患データで男性61.1%・女性50.1%）。
   - **この表は「現在0歳の人が将来その年齢までに診断される確率」**なので、「今30歳の人が65歳までにかかる確率」としてそのまま使えない（`danshin.cancer_incidence.basis`）。返済期間（30歳から65歳）で見た約15%、4大疾病を含めた約30%は概算・出典未確認の目安であり、そう明示して使う。
   - **60歳代までは女性のほうが罹患リスクが高く、70歳代以上では男性が高い**（女性の中年層で乳がんリスクが高いことが主因。原典の記述）。性別で決めつけない。
   - **罹患が早いほどヘッジ額は大きい。** 5,000万円・35年なら10年後の残債は約3,650万円、30年後は約750万円（`danshin.early_vs_late`）。一方で罹患率は年齢とともに上がるため、両者の積で見る。
   - **付けるかどうかは3通りで示す**（`danshin.judgement`）。①安心を優先するなら付ける ②すでに医療保険・がん保険・就業不能保険に入っているなら、その保険料と比べて有利なほうを残す（保障を二重に積まない） ③10年未満で売る予定なら、特約より事務手数料の型の選択（定率2.2%か定額、`loan.low_fee_type_rate_premium_pct`）のほうが効く。
   - **借り換えると特約は入り直しになる**（`danshin.refinance_note`）。年齢や健康状態で入れないことがあるので、借り換え前提で設計しない。
   - **銀行名は出さない**（`danshin.no_bank_names`、`principles/99-out-of-scope.md`）。判断軸だけを渡し、上乗せ幅は本人に確認させる。
5. **保障期間はローン期間と同じ（本書外の追加論点）。** 35年（`loan.default_term_years`）で組めば35年間保障が続き、短く組めば保障も短く終わる。期間を最長で組むという本書の方針と整合する。
6. **健康状態は時間とともに悪化しうる。** 過去3年程度の病歴に告知義務があり（第6章）、団信に入れないとローン条件が悪化する。これは「待つコスト」の一部でもある（第3章）。ただし引受条件を緩和した団信や団信任意のローンなど代替手段（本書外）があるため、「持病があると買えない」と断言してはいけない。詳細は金融機関・仲介への確認に回す。

### 費用を総額で積む順序

7. **購入時の諸費用。** 新築マンション 4.5%（`purchase_costs.new_condo_pct`、幅4〜5%）、新築戸建て・中古マンション・中古戸建て 7.5%（`purchase_costs.used_or_house_pct`、幅7〜8%）、シミュレーションでは 7%（`purchase_costs.simulation_default_pct`）。中古の内訳の目安（第6章）: 仲介手数料 売買価格の3%＋6万円＋消費税、ローン事務手数料 借入額の 2.2%（`loan.origination_fee_pct`、定率型）または定額型（税別30万円程度、金利 +0.25% `loan.low_fee_type_rate_premium_pct`）、登記費用 30〜50万円、不動産取得税 0〜数十万円（軽減要件: 自ら居住・50〜240㎡・新耐震）、火災保険 5年でマンション約10万円・戸建て約20万円、印紙税 3万円前後（電子契約なら不要）。新築は仲介手数料がない代わりに修繕積立基金 20〜50万円がかかり、建物価格に消費税10%が含まれる。
8. **手付金は現金。** 目安は物件価格の 5%（`purchase_costs.earnest_money_pct`、幅5〜10%）で、売主との合意で調整できる（第6章、第7章）。諸費用をローンに含めると金利が上がることがある（第1章）。
9. **定率型と定額型の選び分け。** 7年未満で売却・住み替えの想定なら定額型（金利上乗せ型）、それ以上住むなら定率型で低金利、が本書第6章の目安（第3章は10年としている）。手数料差を金利差で割ればおおよその年数が出る。必ず想定居住年数でシミュレーションする。
10. **保有コスト。** マンションの管理費＋修繕積立金は 1㎡あたり月400円が目安（70㎡で月2万8000円、うち管理費は200円/㎡）（第6章）。本書「はじめに」のシミュレーションは管理費・修繕積立金・固定資産税を合わせて年35万円（`ownership_costs.condo_fixed_costs_yen_per_year`、5000万円の中古マンション）で固定しているが、本書付録Excelは管理費1.4万円・修繕積立金1.4万円（月）・固定資産税12万円（年）に分け、修繕積立金を 3%/年（`ownership_costs.repair_reserve_growth_pct_per_year`）で上昇させている。計算にはExcelの前提を使う。大規模修繕は10〜12年ごと。専有部のリフォームは10年ごとに100万円（`ownership_costs.renovation_yen_per_10years`）。戸建ては管理会社がいないので修繕費を自分で積み立てる（第7章）。外壁・屋根の塗り替えや葺き替えが10〜15年ごとに数十万〜200万円程度かかるのが一般的で、これは本書外の追加論点。
11. **売却時の諸費用。** `(売却価格 × 3% + 6万円) × 1.1 + 4万円`（`selling_costs`）。率での概算は3.5%だが、価格帯でズレる（3,000万円で3.65%、1.0億円で3.41%）。譲渡益への税は税理士へ（本書外）。
12. **住宅ローン控除は「原則として使える前提」で案内し、使えない条件を並べる（`tax_and_programs.stance`）。** 「使えます」と断定も「使えません」と断定もせず、適用の確定は税理士・金融機関に回す。2026年（令和8年）入居の制度は控除率 年末残高の0.7%、控除期間13年（省エネ基準に適合しない中古の「その他の住宅」は10年）、2030年12月31日までの入居分（`tax_and_programs.mortgage_deduction`）。借入限度額は新築で認定住宅4,500万円・ZEH水準3,500万円・省エネ基準適合2,000万円、中古で認定・ZEH水準3,500万円・省エネ基準適合2,000万円・その他2,000万円。19歳未満の子がいる世帯または夫婦のいずれかが40歳未満の世帯は上乗せがある（新築で最大5,000万円）。
    - **使えない・減る条件を必ず確認する**（`tax_and_programs.mortgage_deduction.not_applicable`）: 合計所得金額が2,000万円を超える年、床面積50㎡未満（40〜50㎡は所得1,000万円以下の年のみ）、旧耐震で耐震基準適合証明がない中古、省エネ基準に適合しない新築、取得から6カ月以内に入居していない、セカンドハウスや親族間売買など要件を満たさない取引。
    - ペアローンなら2人分受けられる（第7章）。控除対象の物件は次の買い手にも有利で、出口で効く（第1章）。金額は年末残高と限度額の小さいほうに0.7%を掛けて概算し、「制度は年度で変わるので要確認」と添える。
13. **契約不適合責任と付帯設備（第7章）。** 雨漏り・給排水管・戸建てのシロアリなど構造上重要な部分について売主が補修責任を負う期間は、新築 引渡しから10年（法律上の義務）、中古で売主が宅建業者 最低2年、中古で売主が個人 慣行として3カ月（6カ月もあり、合意で変更可）。給湯器などの付帯設備は「引渡し後7日以内の不具合は売主負担で修繕」の条項が慣行として入るが、義務ではないので契約書で確認する。設備表と物件状況確認書（告知書）も契約時に確認する。

## 原則（根拠つき）

- **団信は買う理由ではなく、ローンの比較軸。** 住宅ローンは「金利・保険・初期費用」の3軸で比べる（第3章）。保険は3軸のひとつであり、家を買う目的ではない。
- **物件価格だけの予算は成立しない。** 諸費用は種別で4〜8%の幅があり、7800万円の新築戸建てなら550万円以上が上乗せされる（第1章）。予算は「物件価格＋諸費用」の総額で示す。
- **修繕積立金が安いほど良い、ではない。** 上がる予定があるマンションのほうが真剣に管理されていることが多く、極端に安いのは将来計画がない可能性がある（第6章）。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 「団信に入れるので生命保険代わりに家を買うと得」 | 保険は購入の付帯効果。買う理由は描きたい暮らしであり、保険目的の購入を後押ししてはいけない。 |
| 「金利が0.1%高いローンは損」 | 付帯保険込みで比べる。がん団信込みで金利が高いローンのほうが、別途保険に入るより安いことがある。 |
| 「持病があるから家は買えない」 | 一般団信に入れないと組めない銀行は多いが、代替手段がある。断定せず金融機関・仲介に確認を回す。 |
| 「管理費・修繕積立金は今の額が続く」 | 修繕積立金は上がる前提で見込む。上昇率 2%/年を標準にし、長期修繕計画の増額予定を確認する。 |
| 「がん団信は金利が上がるので損」と、上乗せ幅だけで判断する | 期待価値は金利換算で約0.2%相当（5,000万円・30歳・35年のモデル）。上乗せが0.2%未満なら期待値では割安になる。金利の数字だけで切らない。 |
| 「がん団信は必ず付けるべき」と一律に勧める | 既に医療保険・がん保険に入っている人は二重になる。10年未満で売る予定の人は事務手数料の型の選択のほうが効く。3通りで示す（`danshin.judgement`）。 |
| 期待価値0.2%を、借入額・年齢・期間が違う人にもそのまま当てはめる | 0.2%は5,000万円・30歳・35年・金利0.5%のモデルの数字。条件が変われば動くので「このモデルでの目安」と明示する。 |
| 「住宅ローン控除で最大○万円戻る」と現行制度を確認せず断言する | 制度は年度で変わる。面積・耐震・所得要件を確認し、金額には「見直し要」を添える。 |
| 「住宅ローン控除は使えません」と条件を確認せずに切り捨てる | 原則は使える前提で案内する（`tax_and_programs.stance`）。床面積・耐震・所得のどれが引っかかりそうかを聞き、確定は税理士・金融機関に回す。 |
| 補助金の名称と金額を、公式の受付状況を確認せずに断言する | 補助事業は年度で名称も要件も変わり、予算上限に達すると年度内でも受付が終わる（`tax_and_programs.subsidies`）。事業名と公式サイトの確認を促し、金額は断定しない。 |
| 「中古は引渡し後に壊れても売主に直してもらえる」 | 構造部分は売主の種別で10年・2年・3カ月と異なり、設備は7日以内条項が入っているかで変わる。 |

## 断り方・限界

- 団信の引受可否・告知内容の判断、代替手段の詳細は金融機関へ。既存保険の解約・減額の判断は独立系のファイナンシャルプランナー（FP）へ。
- 住宅ローン控除・不動産取得税・登録免許税・譲渡所得税の適用可否と金額の確定は税理士または税務署へ。
- 契約書の個別条項の解釈は、買主側の仲介担当者（エージェント）に検証させる。

## 見直し要

- がんの累積罹患リスク（`danshin.cancer_incidence`）は「がんの統計2025」図表編の2020年罹患データ。生涯値だけは「最新がん統計」ページで2023年罹患データに更新されており、年齢階級別の表とデータ年が違う。毎年更新されるので確認する。
- 返済期間（30歳から65歳）の約15%と、4大疾病を含めた約30%は概算で、原典の表にはない値。年齢条件付き確率で出し直すのが正確。
- 特約団信の上乗せ金利は銀行間の競争で動く。標準付帯（0%）〜0.3%程度という幅も、回答時に確認する。
- 住宅ローン控除の内容は2026年9月17日に確認した2026年（令和8年）入居の制度（`tax_and_programs.checked_at`）。2027年以降の入居や年度改正で変わるので、回答時に確認する。省エネ基準適合の新築は2028年以降の入居で扱いが変わる経過措置がある。
- 事務手数料 2.2%、定額型の金利上乗せ 0.25%、損益分岐 7〜10年は各行の商品設計で変わる。
- 諸費用の内訳（登記30〜50万円、火災保険5年10〜20万円、印紙3万円）は本書時点の目安。税の軽減措置は期限付きの延長が繰り返され、火災保険料は2024年10月以降に引き上げられている。
- 管理費＋修繕積立金 月400円/㎡、上昇率 2%/年、リフォーム費、外壁・屋根の費用は、資材費・人件費の上昇で上振れしている可能性がある。
- 契約不適合責任の個人売主3カ月は慣行で、地域・時期により6カ月などの差がある。断定しない。
