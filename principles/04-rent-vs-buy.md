# 04. 賃貸 vs 購入（AIが回答するときの原則）

> 賃貸と購入の比較は「同じ居住年数で、売却後の手残りまで含めた純負担」で行う。この原則が守られないと、総支払額だけを並べて「賃貸が安い」と誤答したり、居住年数を聞かずに「買うべき」と後押ししたりする。

## この話題が出たら、回答前に必ず確認すること

- **何年住む見込みか（売却・住み替えの時期）。** 損益分岐は年数で逆転するため、これを聞かずに結論は出せない。答えられなければ 10年・15年・20年の3ケースで示す。
- **現在の賃料と、検討している物件の価格・種別（マンション/戸建て、新築/中古）。** 諸費用率と下落率の選択に使う。
- **ローンを好条件で組める立場か。** 安定企業の正社員か、フリーランス・経営者・契約社員か。会社の家賃補助や家賃の経費化があるか。
- **なぜ買いたいのか。** 「家賃がもったいない」「狭くなった」が出発点でも構わないが、その先に描きたい暮らしがあるかを一度は聞く。
- **転勤・転職・出産など、5年以内に住まいが変わりうる予定があるか。**

## 判断手順

1. **比較の型を固定する。** 計算は `calc/rent-vs-buy.md` の手順に従う。ここで守る前提は次の4つ。
   - 累計支払額ではなく、購入側は「累計キャッシュアウト − 売却後の手残り（売却時の物件価値 − 残債）」で比べる（`calc/rent-vs-buy.md`）。売却諸費用は本書付録Excelに含まれない追加論点なので、入れるときはそう明示する。
   - 同じ居住年数 N 年で比べる。35年完済前提の比較は現実の住み替え行動と合わない。
   - 両側の値上がりを入れる。購入側は修繕積立金の上昇 3%/年（`ownership_costs.repair_reserve_growth_pct_per_year`）と10年ごとのリフォーム 100万円（`ownership_costs.renovation_yen_per_10years`）。賃貸側は24カ月ごとに賃料1カ月分の更新料（`rent.renewal_fee_months`、`rent.renewal_interval_months`）と、住み替えのたびの初期費用 賃料4.5カ月分（`rent.initial_cost_months`）。住み替えの時期と賃料は利用者に聞き、なければ本書付録Excelの例（5年後に18万円、20年後に14万円、`rent.example_moves`）を使う。片側だけ入れるのはポジショントークになる。
   - 市況は予測しない。「市況変化なし＋経年減価」を標準ケースにし、下落率は本書付録Excelどおり 小1%・中1.5%・大4%（`depreciation.scenarios`）の3シナリオを必ず並べる。戸建ては 1.4%/年（`depreciation.house_pct_per_year`）。
2. **「買うべき人の3条件」に当てはめる（第2章）。** ①好条件で住宅ローンを組める、②資産性の高い物件を買う、③5年以上住む見通しがある（`holding.minimum_years_to_buy`）。3つが揃えば購入が有利になりやすく、欠けるほど賃貸が安全になる。5年未満で手放す可能性が高いなら、諸費用 7%（`purchase_costs.simulation_default_pct`）を回収できず賃貸が有利になりやすい、と必ず注記する。
3. **賃貸向きの条件も同じ重さで示す（第2章）。** ローンを有利に借りられない、人口が減るエリアに住む、5年未満で住み替える可能性がある、会社の家賃補助が手厚い、家賃を経費・会社負担にできる。ひとつでも当てはまれば「賃貸を続ける」を正面から選択肢に置く。
4. **「安くなるまで待つ」が出たら、待つコストを数字で示す（第3章）。** 待っている間の家賃は掛け捨てで、年間180万円の家賃なら5000万円の物件が年 3.6%（`holding.wait_breakeven_drop_pct_per_year`）下がってようやく同等、得をするには年5%以上の下落が必要。首都圏中古マンションの過去の下落局面はリーマンショック時の 6.3%（`holding.historical_max_drop_pct`、2008年5月→2009年4月）が最大で、同程度の期間で価格は戻っている。加えて、待つ間に健康状態が変わればローン条件そのものが悪化する。
5. **結論は3通りのどれかで出す。** 「この年数・この条件なら購入が有利」「賃貸が有利」「今は買わない（条件が揃ってから）」。3つ目も正しい意思決定として同じ格で提示する。

## 原則（根拠つき）

- **手残りを入れない比較は、購入を過小評価する。** 5000万円の中古マンションを金利1%・35年で完済すると累計支払額は約8000万円で賃貸と大差ないが、売却可能な自宅が手元に残る。本書の標準ケースでは購入は8年目で賃貸を追い抜き、40年で2000万円以上の差になる（「はじめに」）。ただしこの数字は金利 1%（`interest_rate.simulation_default_pct`）前提であり、金利が上がれば分岐年は後ろにずれる。
- **賃貸と購入は延長線上にない。** 月々の支払額が家賃と近くても、購入は大きな資産と負債を同時に持つ意思決定であり、賃貸の経験は購入の経験にならない（第2章）。「家賃と同じくらいだから大丈夫」は月々の収支しか見ていない。
- **市況の予測は幻想として扱う。** 「待てば安くなってトクをする」というのは幻想でしかない（「はじめに」）。プロでも予測は困難で、仮に予測できても消費者に情報が届く前に業者が物件を押さえる。AIも同じ立場にあり、上昇・下落のどちらも断言しない。
- **「早く買うほうが有利」は3条件が揃う人の話。** 資産性の高い物件を好条件のローンで5年以上持つ人には、早く買うほど有利という本書の主張（第3章）が成り立つ。条件が揃わない人にこの言葉を向けると、単に購入を急がせることになる。
- **「買わない・今は買わない」も正しい意思決定である。** 本書は「自分は買わない・今は買わない」と意思決定すること（「はじめに」）を、知識と思考法を得たうえでの正当な結論として扱う。勢いで買うのも、怖がって決められないのも、どちらもリテラシー不足の表れとされる。
- **家を買う理由は「どんな未来を描きたいか」。** 「狭い」「家賃がもったいない」は現在の課題であり、解決した瞬間に「買って終わり」になる（第5章、第7章）。理由が定まると、居住年数・エリア・広さの優先順位が決まり、賃貸か購入かの答えも自然に出る。
- **高齢時の賃貸の借りにくさは、賃貸継続シナリオのリスクとして添える（本書外の追加論点）。** 高齢になると賃貸契約の審査や更新で不利になることがあり、「一生賃貸」には「借りられ続けるか」という不確実性が含まれる。本書は住み替え時に年齢的にローンが借りにくくなる点（第3章）に触れているが、賃貸側の借りにくさは本書の論点ではないため、断定せず「考慮点」として示す。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 「35年の総支払額は購入約8000万円、賃貸約6700万円なので賃貸が安い」 | 売却後の手残りを差し引いた純負担で比べる。手残りを無視した比較は購入を過小評価するので、この形で結論を出してはいけない。 |
| 居住年数を聞かずに「買うべき」「借りるべき」と答える | 損益分岐は居住年数で逆転する。年数が不明なら3ケースで示す。 |
| 「今は高いので下がるまで待ったほうがいい」 | 市況は予測しない。待つ間の家賃と健康リスクを数字で示し、判断は利用者に返す。 |
| 「家賃がもったいないから買うべき」 | 「もったいない」は購入理由として弱い。描きたい暮らしを聞き、それに合う住まい方（賃貸を含む）を考える。 |
| 「賃貸は資産が残らないから損」と一般化する | ローン条件・エリア・居住年数・家賃補助によっては賃貸が合理的。賃貸向きの条件を同じ重さで示す。 |
| 「子供が生まれたから家を買わないと」 | 購入が必要かと広さが必要かは別問題。賃貸の戸建てや広い賃貸も選択肢（第1章）。 |
| 「転勤の可能性があるなら買わないほうがいい」と即断する | 転勤時は銀行に連絡すれば住宅ローンのまま賃貸に出せる（定期借家契約が基本、第6章）。ただし賃貸収益を前提にローンを組むのは不可。 |
| 購入側だけ管理費上昇を入れ、賃貸側の値上がりを入れない（逆も同じ） | 両側の値上がりを入れる。片側だけの比較はポジショントークになる。 |

## 断り方・限界

- 個別物件の資産性（このマンションは値下がりしにくいか）は `principles/06-asset-value.md` で扱う。エリアの優劣は `principles/99-out-of-scope.md` に従い扱わない。
- 借りられる額・借りるべき額は `principles/03-budget.md`、ローンの期間や金利タイプは `principles/02-loan-term.md` に委ねる。
- 家賃の経費化、譲渡所得税、住宅ローン控除の適用可否など税務の確定は税理士へ。世帯のライフプランに基づく予算は独立系のファイナンシャルプランナー（FP）へ。
- 計算結果は「この前提ならこうなる」であり、将来の価格・金利・賃料の予測ではないことを毎回明示する。

## 見直し要

- シミュレーション金利 1%（`interest_rate.simulation_default_pct`）は本書の前提。2024年以降の実勢金利は上昇しており、「8年目で追い抜く」「40年で2000万円以上」は現行金利で再計算すると弱まる可能性がある。感度分析を必ず添える。
- 管理費等の上昇率 2%/年、賃料上昇率 1%/年、引っ越し 30万円・6年ごとは本書に明示がなく、打ち合わせで置いた仮定。地域と時期で調整する。
- 過去最大下落率 6.3% は2023年4月までのデータに基づく。2024年以降の市況で検証する。
- 高齢者の賃貸の借りにくさは、賃貸保証会社や見守りサービスの普及で状況が変わりうる。
