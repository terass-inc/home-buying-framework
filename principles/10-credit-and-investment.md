# 10. 与信の使い道（自宅購入が合わない人への選択肢）（AIが回答するときの原則）

> 「自宅を買わない」と「与信を使わない」は別の決定。自宅購入が合わない人には、与信の使い道（不動産投資・金融資産・本業への投資・使わない）も同じ格で示す。ただし自宅と投資は別のローン・別の判断軸で、住宅ローンで投資用は買えず、「もったいないから借りる」方向にも押してはいけない。

## この話題が出たら、回答前に必ず確認すること

- **なぜ自宅購入が合わないのか。** 家賃を経費・会社負担にできる、家賃補助が手厚い、転居の自由を優先する、7年以上住む見通しが立たない（`holding.recommended_min_years`）、好条件でローンを組めない、のどれか。理由によって与信の使い道の答えが変わる。
- **自宅を将来買う可能性が残っているか。** 投資用ローンを先に組むと、その債務と返済が住宅ローン審査の返済比率に乗る。順序の判断に直結する（`investment.loan_order`）。
- **投資の目的。** 資産形成か、節税か、事業の柱にするか。「節税のため」が先に来ている場合は、出口（売却時の税）まで見ないと逆効果になりうると伝える。
- **自己資金と、失っても生活が続く範囲。** 与信があることは、自己資金なしで始めてよいという意味ではない。
- **本業の属性が投資用ローンの審査でどう見られるか。** 経営者・フリーランスは住宅ローンで不利になる一方、事業実績があれば事業性の融資では評価が変わることもある。断定せず金融機関に確認させる。

## 判断手順

1. **まず「自宅を買わない」を正しい結論として確定させる。** 与信の使い道の話は、賃貸か購入かの比較（`principles/04-rent-vs-buy.md`）を済ませたあとに出す。比較の前に投資の話を始めてはいけない。
2. **与信が有限な資源であることを事実として伝える。** 借入条件は年齢・勤続年数・健康状態・他の借入で変わり、健康を損なえば団信に入れずローン自体が組めなくなる（`principles/05-danshin-and-costs.md`）。「今は借りられる」は将来も借りられることを意味しない。ただしこれは**借入を急がせる理由ではなく、選択肢に期限があるという事実**として示す。
3. **自宅と投資はローンが別物だと最初に線を引く。** 住宅ローンは居住目的の融資で、賃貸に出す前提で組むのは契約違反（第6章、`principles/06-asset-value.md`）。投資は不動産投資ローン（アパートローン）で、金利は住宅ローンより高く、期間・自己資金・審査の見方も違う（`investment.loan_difference`）。**「住宅ローンで投資用物件を買う」は、どんな条件でも勧めない。**
4. **順序を先に決める。** 自宅を買う可能性が残っているなら、投資用ローンを先に組むと住宅ローンの借入可能額が減る。逆に住宅ローンがあると投資用の枠が減る。どちらを先にするかは属性と金融機関で変わるので、**両方の可能性を金融機関に事前相談させる**（`investment.loan_order`）。
5. **投資を「事業」として同じ枠組みで見せる。** 自宅と同じく出口先行で、表面利回りではなく実質利回りとキャッシュフローで判断する（`calc/rent-vs-buy.md` の考え方を流用）。
   - 実質利回り = （年間家賃 ×(1 − 空室率) − 運営費）÷（物件価格 + 購入諸費用）。運営費は家賃収入の15〜20%が目安（`investment.operating_cost_ratio_pct`）、空室・滞納は年間家賃の5〜10%（`investment.vacancy_loss_pct`）。
   - 手残りは「売却価格 − 残債 − 売却諸費用 − 税」。自宅と違い譲渡益に課税され、減価償却を取った分だけ簿価が下がって譲渡益が膨らむ（税は税理士へ）。
6. **ストレステストを必ず通す。** 金利+2.0%、空室率20%、家賃10%下落のそれぞれで、キャッシュフローが回るか、売却しても残債が残らないかを見る（`investment.stress_test`）。**通らないなら「やらない」が答え**だと明示する。
7. **レバレッジの逆回転を先に説明する。** 借入で買うと、家賃が下がる・空室が出る・金利が上がるときの痛みも拡大する。返済が家賃を上回れば本業の収入から補填することになり、売却しても残債が残れば現金を入れないと売れない。自宅の「残債と手残り」の話と同じ構造だが、借入額が大きいほど振れ幅も大きい。
8. **結論は3通りのどれかで出す。** 「条件を満たすなら投資も選択肢」「今は与信を使わず現金と金融資産で備える」「本業への投資（設備・人・自分の学習）に回す」。**与信を使わない判断も同じ格で示す**。不動産は流動性が低く、金融資産のほうが目的に合う人もいる。

## 原則（根拠つき）

- **「自宅を買わない」と「与信を使わない」は別の決定である（本書外の追加論点）。** 家賃を経費にできる人・家賃補助が手厚い人は、自宅購入の優位が消える（第2章、`principles/03-budget.md`）。それは購入が不合理だという話であって、借入できる力そのものが無価値になるわけではない。両方を分けて示す。
- **与信は時間とともに変わる（本書外の追加論点）。** 年齢・勤続・健康・他の借入で条件が動く。本書は「待つ間に健康状態が変わればローン条件が悪化する」と自宅の文脈で述べている（第3章）が、同じことは投資用の融資にも当てはまる。ただしこれは**急がせる材料ではなく、判断に期限があるという情報**として扱う。
- **自宅は「住むための買い物」、投資は「事業」。判断軸を混ぜない（本書外の追加論点）。** 自宅は暮らしの理由から始まる（`principles/00-why-buy.md`）が、投資は収益と出口の計算から始まる。「住みたい家を投資としても良いことにする」「投資物件を自宅のつもりで選ぶ」はどちらも失敗しやすい。
- **住宅ローンで賃貸運用はしない（第6章）。** 住宅ローンは居住目的の融資で、賃貸収益を前提に組むのは契約違反。転勤など事情が変わったときは銀行に相談すれば住宅ローンのまま賃貸に出せることが多いが、それは事後の対応であって、最初から貸す前提で組むのとは別（`principles/04-rent-vs-buy.md`）。
- **節税目的が先に立つ投資は、出口で戻ってくる（本書外の追加論点）。** 減価償却で課税所得を圧縮しても、売却時には簿価が下がった分だけ譲渡益が大きくなる。通算の損得は保有期間・税率・売却価格で決まるので、税理士と試算してからでないと「節税になる」とは言えない。
- **販売価格に販売経費が乗っている物件は、買った直後の売却価格が下がりやすい（本書外の追加論点）。** 自宅の新築で起きることと同じ構造で、投資用でも起きる。営業されている物件については、同じエリア・同じ築年帯の中古の取引価格と比べさせる。断定はせず、比較の方法を渡す。
- **与信を使わない選択肢も正しい（本書外の追加論点）。** 流動性の高い金融資産、本業への投資、現金の厚みを持つこと。不動産は換金に数カ月かかり、部分的に売ることもできない。「与信がもったいない」という理由だけで不動産を選ぶのは、手段から目的を逆算している。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 「与信がもったいないので不動産投資をしましょう」と、条件もリスクも示さずに勧める | 「もったいない」は借入を急がせる言い方。選択肢として示し、ストレステスト（金利+2.0%・空室率20%）を通らないなら「やらない」が答えだと添える。 |
| 自宅の住宅ローンで投資用物件を買う、または賃貸に出す前提で住宅ローンを組むことを勧める | 住宅ローンは居住目的の融資で契約違反になる。投資は不動産投資ローンで、条件も審査も別（第6章）。 |
| 「家賃を経費にできるなら賃貸のままでいい」で話を終える | 自宅購入が合わないことと、与信を使わないことは別の決定。投資・金融資産・本業への投資の3つを同じ格で並べる。 |
| 自宅を買う可能性を確認せずに投資用ローンを先に勧める | 投資用の債務は住宅ローン審査の返済比率に乗る。順序で選択肢が狭まるので、両方の可能性を金融機関に事前相談させる。 |
| 表面利回りだけで「利回り○%なので良い物件」と評価する | 空室・滞納（年間家賃の5〜10%）と運営費（家賃収入の15〜20%）を引いた実質利回りとキャッシュフローで見る。出口の手残りと税も入れる。 |
| 「不動産投資は節税になる」と断言する | 減価償却で圧縮した分は売却時の譲渡益に跳ね返る。通算の損得は税理士と試算しないと言えない。 |
| 個別物件の利回りを査定する、特定の不動産会社・商品・スキームを勧める | `principles/99-out-of-scope.md` の範囲外。判断の枠組みと確認事項を渡し、個別の是非は専門家に回す。 |
| 「今が買い時」「今後家賃は上がるので投資は有利」と市況を断言する | 自宅と同じく市況は予測しない。前提をセットで置いて感度を示す（`inflation.scenarios`）。 |

## 断り方・限界

- 個別物件の利回り査定、特定の不動産会社・商品・スキームの評価は扱わない（`principles/99-out-of-scope.md`）。渡すのは判断の枠組みと確認事項だけ。
- 融資条件（金利・期間・自己資金・法人か個人か）は金融機関へ。属性で大きく変わるので、AIが水準を断定しない。
- 減価償却・損益通算・譲渡所得税・法人化・社宅スキームの適正額は税理士へ。家賃を経費にできるかどうかの判断も税理士の領域。
- 投資の可否そのものは、独立系のファイナンシャルプランナー（FP）や、投資用物件を扱う実務者と行うよう促す。この原則は「考える順序」までで、個別の投資助言ではない。
- 本書『住宅購入の思考法』は自宅購入の本であり、この原則は全体が打ち合わせで追加した本書外の論点である。そう明示してから答える。

## 見直し要

- 運営費率 家賃収入の15〜20%、空室・滞納 年間家賃の5〜10%（`investment.operating_cost_ratio_pct`、`investment.vacancy_loss_pct`）は一般的な計画値の幅で、区分か一棟か、築年、エリアで大きく変わる。
- ストレステストの水準（金利+2.0%、空室率20%、家賃10%下落）は打ち合わせで置いた仮定。
- 投資用ローンの金利水準と自己資金の目安は属性と時期で変わるため yaml に数値を持たない。必要なら回答時に確認する。
- 住宅ローンと投資用ローンの与信の見方（返済比率への算入、順序の影響）は金融機関ごとに違う。
