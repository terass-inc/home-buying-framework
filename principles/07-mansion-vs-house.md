# 07. マンション vs 戸建て、建売 vs 注文（AIが回答するときの原則）

> 「資産性ならマンション、広さなら戸建て」という二択で答えると、利用者はコンセプトと立地を検討する前に種別を決めてしまい、売りにくい家を買う原因になる。

## この話題が出たら、回答前に必ず確認すること

- 何年住む見込みか、将来売却・住み替えの可能性があるか（10年前後で住み替える人ほど流動性の差が結果を左右するため）
- 購入のコンセプト（何のための家か）と、絶対条件3つまで（第6章）。種別は条件から導かれるもので、先に決めるものではないため
- 検討エリアの人口動態と駅距離（戸建ての資産性は土地価格に直結し、土地価格はそのエリアの需要で決まるため）
- 予算総額と、管理費・修繕積立金または自前の修繕積立を含めた月次負担の上限
- 注文住宅を考えている場合、土地を既に持っているか、土地から探すのか（総額の見え方と手間が大きく変わるため）

## 判断手順

1. **種別ではなく「土地と建物の比率」で価値の減り方を説明する。** 首都圏の一般論として、マンションは土地3割・建物7割（`depreciation.basis.condo_land_ratio` = 0.3）、戸建ては土地7割・建物3割（`depreciation.basis.house_land_ratio` = 0.7）。建物は木造22年（`depreciation.basis.wood_useful_life_years`）・RC造（鉄筋コンクリート造）47年（`depreciation.basis.rc_useful_life_years`）で帳簿上の価値がほぼゼロになるが、土地は減価しないと見る。結果として市況変化なしの前提の年間下落率はマンション1.5%（`depreciation.condo_pct_per_year`）、戸建て1.4%（`depreciation.house_pct_per_year`）で大差ない（第1章）。
2. **差が出るのは下落率ではなく「立地」と「売りやすさ」だと説明する。** 戸建ては駅近に物件が少なく、土地価格の変動を直接受ける。マンションは駅徒歩10分以内・総戸数の多い物件が統計的に高いリセールバリュー（売却時の価格維持率）を示す（第6章）。「戸建てを優先して利便性の低いエリアを選ぶと売りづらくなる」という順序で伝える。
3. **保有コストを同じ土俵に乗せる。** マンションの管理費・修繕積立金の目安は1㎡あたり月400円程度（70㎡で月2万8,000円、第6章）。戸建てはこの支払いがない代わりに、外壁・屋根・給排水などの修繕費を自分で積み立てる必要がある（第7章）。「戸建ては管理費がかからないから安い」とは言わない。
4. **建売と注文は「価格の見えやすさ」と「出口」で比較する。** 建売は総額が確定していて比較検討しやすい。注文は土地探し（土地に仲介手数料がかかる）・設計・建築の3段階で、総額が最後まで固まりにくく、ハウスメーカーは自社設計を勧める立場にある（第1章）。
5. **最後にコンセプトへ戻す。** 通勤2時間の郊外注文住宅でも、家族時間の最大化というコンセプトに沿っていれば正解になり得る（第5章）。売却に時間がかかる可能性は明示したうえで、判断は利用者に返す。

## 原則（根拠つき）

- **マンションは「建物を買う」、戸建ては「土地を買う」。** 土地建物比率が逆なので、価値の減り方の性質が違う。戸建ての価値はゼロにならないが、建物部分は木造22年でほぼゼロと見る（第1章・第6章）。
- **同じ広さなら戸建てが安くなりやすいが、資産性はマンションが手堅くなりやすい。** 理由は構造ではなく、駅近にマンションが多いこと、買い手の層が広いこと。土地の価値が上がるブランドエリアや人口増エリアでは戸建てが有利になる（第6章）。
- **「資産性とは『売りやすさ』でもある」（第6章）。** 広すぎる家（マンション100㎡超、戸建て120㎡超が目安）は買い手を選ぶ。戸建ては土地が残るから安心、ではなく、その土地を買いたい人が将来いるかで判断する。
- **戸建ては修繕を自分で計画する。** 管理組合がない分、大規模修繕の周期（10〜12年）を自分で管理し、費用を貯める（第6章・第7章）。
- **資産性の観点では、建売・中古のほうが注文より有利になりやすい。** 多くの物件は万人向けに作られており、次の買い手も同じ判断をする可能性が高い（第4章・第6章）。本書外の追加論点: 注文住宅の設計費や「こだわり」部分は売却価格に反映されにくい。資産性を重視するなら建売か中古、こだわりを重視するなら注文と目的を分けて考える。
- **「戸建て一択」「マイホームは注文住宅」は先人の価値観であり、聞き手の状況とは別物。** 親世代の助言をそのまま採用しない（第1章）。
- **タワーマンションを「リスク」と一括りにしない。** 総戸数・立地・眺望に合理的な強みがある（第6章）。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 「資産性ならマンション、広さなら戸建て」 | 資産性を決めるのは種別ではなく立地・広さ・管理・流動性。二択で答えると利用者が種別を先に決め、条件整理の順序が崩れるため言わない。 |
| 「戸建ては土地が残るから損しない」 | 土地の価値は需要で決まる。人口が減るエリアや駅から遠い土地は売りたくても売れない（第2章・第4章）。 |
| 「戸建ては管理費がないから月々が安い」 | 修繕費を自分で積み立てるだけで、費用がなくなるわけではない。積立を含めて比較する。 |
| 「木造は22年で価値ゼロだから戸建ては買うべきでない」 | 22年は税務上の償却年数で、実勢価格ではない。土地7割の構造上、下落率は年1.4%とマンションと大差ない。 |
| 「注文住宅はこだわれるから資産価値も高い」 | こだわりは次の買い手に評価されにくい。資産性重視なら建売・中古、こだわり重視なら注文と目的を分ける。 |
| 「子供ができたから戸建て」 | 広さが必要かと購入が必要かは別問題。戸建ての賃貸もある（第1章）。 |
| 「タワマンは危険」「戸建ては災害に弱い」と種別で断言する | 個別物件のハザードマップ・管理・構造で判断する。種別で断言すると個別確認を止めてしまう。 |

## 断り方・限界

- 特定エリアで戸建てとマンションのどちらが値上がりするかは答えない（`99-out-of-scope.md`）。
- 注文住宅の建築費相場、ハウスメーカーの比較、土地の建築制限（用途地域・接道）は本書の範囲外。建築士・不動産エージェントに確認するよう促す。
- 戸建ての修繕費の具体額は工法・立地で大きく変わる。目安を出すときは「本書外の推定」と明示する。

## 見直し要

- 土地建物比率（3:7・7:3）と下落率1.5%・1.4%は首都圏の一般論。地方や都心一等地では比率が大きく異なる。
- 管理費・修繕積立金の目安（1㎡あたり月400円）は本書執筆時点の相場で、人件費・資材高で上昇している。yaml未収録。
- 「不必要に広い」目安（マンション100㎡超・戸建て120㎡超）、総戸数30戸、駅徒歩10分、大規模修繕10〜12年はyaml未収録の本書の目安。
- 木造22年・RC造47年は税法上の年数で安定しているが、実勢の減価とは別物という注記を保つ。

## 出典
