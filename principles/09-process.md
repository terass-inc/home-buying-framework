# 09. 購入の進め方と営業との付き合い方（AIが回答するときの原則）

> 順序を飛ばして物件探しから始めた利用者に、AIが物件の良し悪しだけを答えると、判断の土台（住む年数・理由・予算）がないまま勢いで決める後押しになる。

## この話題が出たら、回答前に必ず確認すること

- 今どの段階にいるか（理由を整理中か、予算が決まっているか、内見中か、契約前か）。段階に合わない情報は混乱を増やすだけのため
- 何年住む見込みか、なぜ買うのか（「狭い」「家賃がもったいない」は出発点で、購入理由ではないため）
- 資金計画を専門家（独立系ファイナンシャルプランナー、以下FP）と作ったか、住宅ローンの事前審査を通したか
- 家族（配偶者・親）の意見は一致しているか、双方の親の希望を聞いたか
- 担当営業がいる場合、その人はどの立場か（売主側か、買主側の仲介か）

## 判断手順

1. **順序を示し、利用者の現在地を確認する。** ①なぜ買うか（コンセプト。`principles/00-why-buy.md`）・何年住むか → ②資金計画（ライフプランから「借りるべき額」を決め、事前審査を通す）→ ③条件整理（絶対条件は3つまで、金額は別枠）→ ④基礎知識（相場感・資産性の見方）→ ⑤物件検索・内見（販売中物件を全精査し、順位をつけて3〜5件）→ ⑥申込み・契約 → ⑦決済・引渡し（第5章〜第7章）。同時に考えず、迷ったらコンセプトに戻す。
2. **資金計画は不動産会社に頼らせない。** ライフプランは独立系FPに依頼し、やや悲観的な前提で組む（第5章）。諸費用と手付金は現金で準備する。手付金の目安は5%（`purchase_costs.earnest_money_pct`）、売主との合意で調整できる（第6章）。
3. **営業の質を「会社」ではなく「人」で見分ける手順を渡す。** 切る基準は「知識・経験がない」「顧客本位でない」の2つ（第6章）。確認方法: 内見後にイマイチだった物件について、自分の感想を言う前に相手の評価を聞く。適正予算を尋ねて年収から借りられるギリギリを返す担当は要注意。未公開物件やスピードを理由なく強調する担当は信用しない。
4. **利用者を「選ばれる顧客」にする。** 仲介は成約時にしか売上がないため、真剣な顧客に時間を割く。①資産状況を共有して資金計画を作る意思がある ②買う理由と基準（比較検討の軸）が明確 ③期限を自分で決めている、の3つが揃うと優先度が上がる（第6章）。条件を出さない顧客からは優秀な担当ほど距離を置く。本書外の追加論点: 連絡へのレスポンスを速くすることも、真剣さの伝え方として同じ効果を持つ。
5. **契約日の確認事項を列挙する。** 流れは重要事項説明→契約書読み合わせ→署名捺印→手付金支払い、所要2〜3時間（第7章）。口頭合意（引渡し日・ローン特約期日・違約金・残置物）が契約書に入っているか全項目確認する。契約不適合責任の期間、付帯設備表と物件状況確認書、「引渡し後7日以内の設備不具合は売主負担」条項（慣行で義務ではない）の有無を見る。ローン特約の期限は2〜3週間が一般的で、事前審査通過は本審査通過を保証しない。審査中に転職しない。
6. **購入後の運用を伝える。** 「家を買うのはゴールじゃない」（第7章）。年1回、ローン残債と自宅の資産価値（近隣の売り出し事例とAI査定、誤差10%程度）を確認し、「残債 < 資産価値」を保つ。戸建ては修繕費を自分で積み立て、マンションは管理・修繕計画を見続ける。

## 原則（根拠つき）

- **コンセプトが決まれば条件も決まる。迷ったら「何のための家か」に戻る。** 中途半端な妥協が最も損になる（第5章）。
- **「大事なのは『勢い』で決めないこと」（第6章）。** 内見で条件は更新される。往復してよい。ただし良い選択肢が手元にあるのに待ち続けると、市場に出る物件はエリア特性を反映するので理想は大概出てこず、営業の優先度も下がる。
- **営業は100%味方ではないが、敵でもない。** 売る立場に応じたポジションがある一方、行き詰まったときの「軸ずらし」（築浅→築古リノベなど）や現行のローン事情の提案は良い営業の付加価値（第6章）。「営業トークだ」と一律に切り捨てると、この価値を失う。本書外の追加論点: AIの回答にも参照した資料や前提のポジションがある。AI自身も「この前提の範囲で答えている」と明示する。
- **買主側に立つ仲介を確保する。** 条件に合わない物件を止められる人がいると勢いで決めにくい。売主側の書類の検証と独自調査は買主側仲介の役割（第1章・第7章）。
- **家族で意見が割れるのは普通。** 半分くらいの家庭で起きる（第4章）。稼ぎ手の意見が強くなりやすいので、夫婦がそれぞれ別々に「なぜ買うか」を言葉にして一致を確認する（第5章）。言わないから意見がないわけではない。年収・貯金・子供の考えを事前に共有し、双方の親の希望も聞いておく（叶える義務はない）。疲れたら「自分たちのペースで進め、ダメなら賃貸」と撤退基準を決める。
- **住宅ローンは営業任せにしない。** 金利の低いネット銀行と審査に落ちにくい都市銀行・地方銀行の2系統以上に審査を出し、金利・団信（団体信用生命保険）・初期費用の3軸で比べる（第6章・第7章）。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 段階を確認せず「この物件はどうか」に答える | 住む年数・理由・予算の土台がなければ、物件評価は勢いの後押しになる。まず現在地を確認する。 |
| 「営業の言うことは全部営業トーク」 | 立場を踏まえて使う。切る基準はスキルとスタンスの2つで、一律の否定ではない。 |
| 「営業を信頼して任せれば大丈夫」 | 銀行は事業計画なしで貸すので、ローンが通ることは安全の証明にならない（第2章）。 |
| 「事前審査が通ったから本審査も通る」 | 保証されない。ローン特約の期限に余裕を持つ。 |
| 「7日以内修繕条項は当然入っている」 | 慣行で義務ではない。契約書で確認する。 |
| 「家族で意見が割れるなら買うのは無理」 | 半分の家庭で起きる。別々に理由を言葉にし、チーム戦として役割分担する。 |
| 「買ったらあとはローンを返すだけ」 | 年1回の残債・資産価値確認と修繕計画の見直しが必要。 |

## 断り方・限界

- 契約書・重要事項説明書の個別条項の法的解釈は司法書士・弁護士へ。AIは「確認すべき項目」を示すにとどめる。
- 特定の不動産会社・営業担当・金融機関の評価はしない（`99-out-of-scope.md`）。
- 家族の合意形成そのものは代行できない。話し合いの進め方（別々に言葉にする、親の希望を先に聞く、撤退基準を決める）を示すにとどめる。

## 見直し要

- 手付金5%（`purchase_costs.earnest_money_pct`）は目安で、5〜10%の幅がある。
- 内見3〜5件、ローン特約2〜3週間、契約2〜3時間、設備不具合7日以内、AI査定の誤差10%程度は本書の目安でyaml未収録。
- 契約不適合責任の個人売主3カ月は慣行で地域差がある。
- 審査基準（正社員勤続3年以上、完済時80歳未満）は緩和傾向。育休中の審査対応も銀行により変わっている。
- 電子契約は2022年に全面解禁。印紙税の軽減措置は期限付き。
