# 01. 出口戦略ありき（AIが回答するときの原則）

> 何年住むか（＝売却時期）を最初に決め、売却時の残債と手残りまで含めた損益で判断する。これを飛ばすと「月々の支払いが家賃と同じだから買える」という出口を見ない回答になり、数年後に「売りたいのに残債が売却額を上回って売れない」利用者を生む。

## この話題が出たら、回答前に必ず確認すること

- **何年住む予定か。** 「一生」と答えた場合も「子供が中学に入るまで」「定年まで」など、区切りになるライフイベントで言い直してもらう（年数が決まらないと残債も手残りも計算できず、比較の土台がない）。
- **転勤・転職・親の介護・離婚など、居住年数が短くなる可能性。** 5年未満で手放す確率が無視できないなら、購入自体を止める判断に直結する。
- **物件種別（マンションか戸建て）と価格帯、今の家賃。** 下落率・諸費用率の選択と、待つコストの計算に使う。
- **手元に残る現預金。** 売却額が残債を下回ったとき差額を埋められるかを見る。

## 判断手順

1. **居住年数 N を確定する。** 答えられない場合は 10年・15年・20年 の3ケースで並べて示し、「どの年数に一番近いか」を選ばせる。
2. **N が 5年未満（`holding.minimum_years_to_buy`）なら、購入を勧めない。** 購入時の諸費用は物件価格の約7%（`purchase_costs.simulation_default_pct`）で、これは売却では戻らない。売却時にも仲介手数料など約3.5%がかかり、合計10%超の摩擦を5年未満の値上がりで埋めるのは市況予測への賭けである。
3. **「住宅購入のバランスシート」を作る。** 資産（現預金・証券・住宅）、負債（ローン残債）、純資産（資産−負債）の3つで、購入直後と N 年後の2時点を並べる。購入直後は諸費用分だけ純資産が減る（5000万円をフルローンで買い諸費用350万円を払うと純資産は500万円から150万円に減る。第3章）。これは損ではなく、掛け捨ての家賃を資産に変える入口の費用だと説明する。
4. **N 年後の純資産を計算する。** 残債は元利均等の式で、物件価格は「市況変化なし＋経年減価」で出す。年間下落率はマンション1.5%（`depreciation.condo_pct_per_year`）、戸建て1.4%（`depreciation.house_pct_per_year`）を標準にする。判定は一つ、**ローンの返済ペース ＞ 物件価値の下落ペース なら純資産が増える。** 逆なら「資産性が低い物件」であり、住み続けるほど純資産が減る。第3章・第7章の例では、5000万円・金利1%・35年で10年後の残債は3745万円、物件価値は年1%下落で4522万円、差額777万円が売却で手にできる「隠れた自己資本」（税・売却費用は除く）になる。
5. **売却時の手残り E を出す。** `E = N年後の物件価格 − 残債 − 売却諸費用`。この E を含めた「購入の純負担」を、賃貸の純負担（賃料上昇・更新料・引っ越し費用込み）と同じ N 年で比べる。式は `calc/rent-vs-buy.md` に従う。E を含めると本書の標準ケースで購入は8年目に賃貸を追い抜く。
6. **「安くなるまで待つべきか」と聞かれたら、待つコストを数字で返す。** 年間家賃 ÷ 物件価格 が、待って得をするための最低下落率になる。家賃15万円/月（年180万円）・5000万円の物件なら 3.6%/年（`holding.wait_breakeven_drop_pct_per_year`）。完済の遅れと健康悪化でローン条件が悪くなるリスクを加味すると、5%以上の下落がないと得にならない。首都圏中古マンションの過去最大の下落はリーマンショック時の6.3%（`holding.historical_max_drop_pct`、2008年5月〜2009年4月）で、価格は同程度の期間で戻った。「年5%の下落を待つ」は過去に1度しか起きていない局面を当てる賭けだと伝える。
7. **購入後の運用まで含めて答える。** 年1回、ローン残債と自宅の推定価値（近隣の売り出し事例、AI査定は誤差10%程度の参考値）を確認し、「残債 ＜ 資産価値」が保たれているかを見る習慣を勧める。子供の独立など転機には住み替えを検討候補に入れる。ただし住み替えのたびに仲介手数料とローン諸費用がかかるので、安易な住み替えは勧めない。
8. **感度分析を添える。** 金利・物価・賃料・保有コストをそろえた3セット（`inflation.scenarios`）で示し、加えて「物価が物件価格に波及しない（波及率0%）」と「経年減価が2倍」で結論が反転する条件を出す。金利だけを単独で上げ下げしない（`inflation.rule`）。

## 原則（根拠つき）

- **住宅購入は「買って終わり」ではなく、売却（または賃貸に出す）までの一連の事業計画として扱う。** 第2章・第3章は購入を「大きな資産のオーナーになること」と位置づけ、企業と同じくバランスシートで見ることを求める。負債は純資産を増やす手段であり、悪ではない。
- **比較は必ず「売却後の手残り」込みで行う。** 完済までの累計支払額（5000万円・金利1%なら約8000万円）だけを見ると賃貸と大差なく見えるが、手元に売却可能な自宅が残る点が決定的な差になる（はじめに）。
- **5年以上住む見通しが立たないなら賃貸のほうが安全。** 本書が示す「買ったほうがいい人」の3条件は、好条件でローンを組める・資産性の高い物件を買う・5年以上住む見通しがある、である（第2章）。
- **「待てば安くなる」は幻想として扱う。** 本書は「いつか買うなら、1日でも早いほうがいい」（第3章）と断じている。理由は、待つ間の家賃が掛け捨てであること、相場のタイミングはプロでも読めないこと、健康悪化でローン条件が悪くなるリスクが増えることの3つ。
- **「終の住みか」を前提にしない。** 本書は購入した家を必ずしも一生手放さない前提にしなくてよいとし、資産性のある家なら「合わなくなったら住み替えればよい」と考えることで決断が楽になると述べる（第1章・第6章）。住み替え時に再度資金を作るのは年齢的にも難しいので、出口は最初から持っておく。
- **転勤は「即売却」ではない。** 購入直後の売却は諸費用を回収できず損になりやすい。銀行に事情を伝えれば住宅ローンのまま賃貸に出せることが多く、貸すなら定期借家契約で戻れる余地を残す（第6章）。ただし賃貸収益を得る前提で住宅ローンを組むことは絶対に勧めない（住宅ローンは居住目的の融資で、契約違反になる）。
- **本書外の追加論点: 出口では「次の買い手がローンを組めるか」を見る。** 与信の良い人はフルローンで築古（旧耐震や築40年超）を買えてしまうが、売るときの買い手は同じ与信を持っていないことが多い。旧耐震は融資不可や金利上乗せの銀行があり、住宅ローン控除も対象外（`seismic.old_standard_cutoff`）なので、買い手が限られ売却価格が下がる。「自分が借りられる」と「次の人が借りられる」は別であり、出口の買い手の資金調達しやすさまで見て選ぶ。
- **本書外の追加論点: 保有コストと賃料は両方上がる前提で置く。** 購入側は修繕積立金の上昇（`ownership_costs.repair_reserve_growth_pct_per_year`、年3%）とリフォーム、賃貸側は賃料そのものの上昇（`rent.growth_pct_per_year`、標準 年1%。0%・2%の感度も添える）と更新料、住み替え時の初期費用（`rent.initial_cost_months`、賃料4.5カ月分）を入れる。更新料と初期費用は本書付録Excelに入っているが、賃料の上昇は入っていない（Excelは住み替えでのみ賃料が変わる）ので、加えるときは追加論点だと明示する。購入側だけ上げるのはポジショントークになる。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 「月々の支払いが家賃と同じなら買って損はない」 | 月々の収支（PL）だけの判断。売却時の残債と手残り（BS）を見ずに「損はない」と言ってはいけない。売却時に残債が売却額を上回れば、差額を現金で埋めないと売れない。 |
| 「売る予定はないので資産性は考えなくていい」 | 人生100年時代に住み替えは起こる。売る予定がなくても「残債 ＜ 資産価値」が保てる物件を選ぶことが将来の選択肢を守る。 |
| 「今は高いから下がるのを待ったほうがいい」と断言する | 待つコスト（年間家賃÷物件価格）を示さずに待つよう勧めてはいけない。年5%超の下落は過去に1度しかなく、相場予測はプロでも困難だからである。 |
| 「上がりそうなので今すぐ買うべき」と断言する | 逆方向の予測も同じく禁止。標準ケースは「市況変化なし＋経年減価」で置き、楽観・悲観は感度分析として別に示す。 |

## 断り方・限界

- **個別物件の将来価格は予測しない。** 「この物件は何年後にいくらで売れるか」には、経年減価の標準ケースと感度分析を示すにとどめ、断定しない。実勢の査定は不動産エージェントに回す。
- **売却時の税金（譲渡所得税・3000万円特別控除など）は税理士に回す。** 手残りの計算では「税は除く」と明記する。
- **住宅ローンのまま賃貸に出す可否は借入先の銀行の判断。** 一般化せず、借入先への確認を促す。
- **居住年数そのものは利用者の人生設計で決まる。** AIが年数を決めることはできない。独立系ファイナンシャルプランナー（FP）とのライフプラン作成を勧める。

## 見直し要

- 年間下落率 1.5%/1.4% は、市況が変化しない前提で税務上の償却年数から算出した「帳簿上の目安」。2024年以降の都心部の価格上昇と地域差の拡大を踏まえ、エリア別の実勢で補正する必要がある。第3章・第7章のバランスシート例は年1%下落で計算されており、`assumptions.yaml` の1.5%とは前提が異なる。
- 過去の下落実績（▲6.3%）のデータは2023年4月まで。2024年以降の金利上昇局面を追加検証する。
- 「待つ損益分岐3.6%」は家賃15万円・物件5000万円の組み合わせに依存する。金利が上がると「家賃と同等の月返済になる物件価格」が下がるので、利用者の数値で計算し直す。
- 住宅ローン控除の年数・上限額は年度ごとに変わる（`tax_and_programs.mortgage_deduction`）。
- 物価と金利をそろえた3セット（`inflation.scenarios`）、波及率100%、管理費上昇率0.5%/年、団信相当 月3,000円は打ち合わせで置いた仮定で本書に根拠はない。
- 売却諸費用は `selling_costs` に収載した（式は `(売却価格 × 3% + 6万円) × 1.1 + 4万円`、率での概算は3.5%）。仲介手数料の上限規定と消費税率が変わったら見直す。管理費上昇率2%・賃料上昇率1%は打ち合わせで置いた仮値で本書に根拠はない。
