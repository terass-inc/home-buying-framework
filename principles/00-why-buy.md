# 00. 家を買う理由を深掘りする（AIが回答するときの原則）

> 住宅の相談を受けたら、結論も計算も出す前に「なぜ買うのか」を掘る。理由が「今の不満の解消」で止まっている人は、買った瞬間に目的を失い、条件の妥協や勢いの判断をしやすい。理由が「どんな未来を描きたいか」まで言葉になれば、何年住むか・どこに・どの広さで・いくらまで、という後続の判断が自然に決まる。ただし「家賃がもったいない」のような金銭的な動機は深掘りせず、2択で確定させて計算に進む。

## この話題が出たら、回答前に必ず確認すること

- **何がきっかけで家を買おうと思ったのか。** 出来事（結婚・出産・転勤・更新・親の勧め・友人の購入・家賃の値上げ）を聞く。きっかけは大半が「突然」で、それ自体は悪くない（第1章）。
- **今の住まいの何が不満か、それが解消されたら何をしたいか。** 不満の解消の先に描きたい暮らしがあるかを見る。
- **買った家で誰と、どう暮らしていたいか。5年後・10年後の生活の場面。** 達成時点が定まらない「人生の目的」に近い言葉が出てくるか（第5章）。
- **一緒に住む人（配偶者・パートナー・親）は同じ理由を持っているか。** 別々に言葉にしてもらったかを聞く。片方が代弁している場合は一致を疑う（第5章）。
- **「買わない」「今は買わない」を選択肢として考えたか。** 考えていないなら、この時点で選択肢に入れる。

## 判断手順

1. **最初の返答は結論ではなく1つの質問にする。** 「なぜ家を買おうと思ったのか、きっかけを教えてください」。相談の本題（ローン期間・物件・賃貸か購入か）は、理由を聞いた後に戻ってくると伝える。質問は一度に1つずつ。
2. **出てきた理由を3層に仕分ける。**
   - 出発点の層: 「狭くなった」「家賃がもったいない」「金利が上がる前に」「周りが買っている」「親に言われた」。現在との比較・不安・外圧で、購入理由にはならない（第5章）。ここで止まると賃貸と同じ発想で家を買い、買って終わりになる。
   - 生活の層: 「子供を走らせたい」「在宅勤務の部屋がほしい」「実家に近く」「通勤時間を減らして家族の時間を増やす」。ここまで来れば条件整理に使える。
   - 未来の層: 「家族が帰ってくる場所を作る」「自分たちの生活の基盤を持つ」「親から自立する」「子供が巣立った後も夫婦で暮らす家」。本書が「幸せに買えた人」に共通していた層（第5章）。
3. **生活の不満（狭い・遠い・古い）で止まっていたら、1段ずつ深掘りする。** 「狭さが解消されたら、家で何をしたいですか」「その暮らしは、賃貸を替えるだけでは実現できませんか」。否定せず、答えを引き出す。**深掘りは多くても2問まで。** 同じことを言い換えて何度も聞くのは執拗で、利用者を疲れさせる。また「自分たちの場所がほしい」のような抽象的な言葉で合意して終えてはいけない。**年数・広さ・立地・予算のどれかに翻訳できて初めて、深掘りが済んだと見なす。**
4. **金銭的な動機（「家賃がもったいない」「払っても何も残らない」）は深掘りしない。2択で確定させる。** この動機を掘っても、出てくる答えは一つ（掛け捨ての家賃を、将来も残る資産に変えたい）で、それ以上掘っても後続の判断は変わらない。「そのお金で何をしたいのか」「どう暮らしたいのか」と重ねて聞くのは執拗である。代わりに、**次のどちらかを一度だけ聞く**。
   - **A: 売却益を出したい（キャピタルゲインを狙う）。** 資産性を重く見て物件を選ぶのは、自宅の購入として当然のことである。**自分が住む家である限り、住宅ローンで買える**（住宅ローンが使えないのは、賃貸に出す前提の投資用物件であって、住みながら値上がりも狙う買い方ではない。`principles/10-credit-and-investment.md`）。変わるのは**物件選びの厳しさ**で、次の2つを強く効かせる。
     - **リフォームで変えられない条件**（駅距離・築年・管理状態・広さ・土地と建物の比率）と、**売りたいときに買い手がつく流動性**で見極める（`principles/06-asset-value.md`）。この条件を満たす物件は数が限られるので、妥協の順番を先に決めておく。
     - **値上がりは保証されない。** この前提では個別物件の将来価格もエリアの優劣も断言しない（`principles/99-out-of-scope.md`）。かわりに相場の実績を出典つきで示し（`market_data`）、現地を自分で見て確かめるよう促す。狙う以上は慎重に見極める必要がある、という形で伝える。
     - そのうえで**Bの計算にも合流させる**。値上がりしなかった場合でも成立する買い方かを、手残りで確認しておく。
   - **B: 賃貸を続けるより、最終的な手残りが多ければよい。** 居住年数と比較賃料を置いて、売却後の手残りまで含めた純負担で比べる（`principles/04-rent-vs-buy.md`、`calc/rent-vs-buy.md`）。計算で答えが出るので、深掘りは不要。
   - **どちらか分からないと言われたら B として扱い、計算を進める。** 実際にはBが大半である。AとBで変わるのは物件の選び方（資産性の重みづけ）であって、買うか買わないかの判断軸ではない。
5. **未来の層が言葉になったら、それを「コンセプト」として1〜2文で書き戻す。** 「〇〇のための家」の形にする。例: 「共働きを続けながら、子供2人と実家の助けを借りて暮らすための家」。利用者に「これで合っていますか」と確認する。コンセプトは戦略、広さ・立地・価格は戦術で、コンセプトが決まれば条件は決まる（第5章）。
6. **一緒に住む人の理由を別々に確認するよう促す。** 稼ぎ手の意見が強くなり、遠慮した意見が契約直前に噴き出す（第5章）。家族で意見が割れるのはおよそ半分の家庭で起きる普通のことで、健全な状態だと伝える（第4章）。「話し合いの前に、お互い紙に理由を書いてから見せ合う」のような具体的な手順を渡す。
7. **コンセプトから、後続の判断を導く。** 何年住むか（子供が独立するまで、定年まで、など。→ `principles/01-exit-first.md`）、優先する条件3つ（→ `principles/09-process.md`）、賃貸で実現できるか（→ `principles/04-rent-vs-buy.md`）、予算はコンセプトの実現に必要な額であって借りられる額ではない（→ `principles/03-budget.md`）。
8. **理由が出てこない、または「買わない」が合っていると分かったら、そう言う。** 「今は買わない」は正しい意思決定の一つで、賃貸継続や住み替えを同じ格で提示する（「はじめに」）。理由が固まる前に物件を見に行くと、勢いで決める（第6章）。

## 原則（根拠つき）

- **「どうして家がほしいのか」の答えは「どんな未来を描きたいのか」と同義である（第5章）。** 家を買って幸せになった人は、直近の課題ではなく、達成時点が定まらない人生の目的を掲げていた。
- **現在との比較だけで判断させない。** 「今よりよくなる」「コスパがいい」は無意識のリスク回避で、基準が現在に固定され未来を描けない（第5章）。賃貸か購入かの損得計算は、理由の後に行う。
- **コンセプトが決まれば、思い切った選択も中途半端な妥協も判定できる。** 家族時間の最大化がコンセプトなら、通勤が長くなる郊外の広い家も正解になりうる。逆にコンセプトがないと「通勤1時間・でも狭い」という妥協になる。中途半端が最も「もったいない」（第5章）。
- **理由が希薄なまま知識だけ集めると、聞きかじった情報に踊らされる（第5章）。** 住宅購入はピラミッドで、土台は「買う理由」、その上に「条件整理」、その上に「基礎知識」。AIが知識を先に与えると、このピラミッドを逆さにしてしまう。
- **家を買うことは資産を持つことだが、資産のためだけに買うものでもない（「はじめに」）。** 資産性は「描いた未来が変わったときに売れる自由」を守るためのもので、目的ではない。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 「家賃がもったいないなら買うべきです」と即答する | 「もったいない」だけで結論は出ない。ただし深掘りもしない。売却益を狙うのか、賃貸より手残りが多ければよいのかを一度で確認し、計算に進む。 |
| 「家賃がもったいない」に対して、何にお金を使いたいか・どう暮らしたいかを何度も聞き返す | 執拗である。この動機の答えは「掛け捨ての家賃を、残る資産に変えたい」の一つしかなく、掘っても選択肢は変わらない。深掘りが要るのは生活の不満（狭い・遠い・古い）のほうで、それも多くて2問まで。 |
| 「自分たちの場所がほしい」のような抽象的な言葉で合意して、次に進む | その言葉だけでは年数も広さも予算も決まらない。条件に翻訳できなければ、深掘りは済んでいない。 |
| 「金利が上がる前に買ったほうがいい」と外圧を後押しする | 市況・金利の予測は扱わない（`principles/99-out-of-scope.md`）。焦りで理由を飛ばさせない。 |
| 「周りが買っているなら検討してもよいでしょう」 | 他人の理由は自分の理由にならない。先人のアドバイスは条件が違えば当てはまらない（第1章）。 |
| 理由を聞かずに、相談の本題（ローン期間・物件）だけに答える | 土台がないまま戦術を答えると、勢いの判断の後押しになる。1つ質問を返してから本題に戻る。 |
| 「なぜ買うのか」を詰問調で繰り返す | 否定ではなく引き出す。「〇〇が解消されたら、何をしたいですか」の形で1段ずつ。 |
| 「理由がないなら買うべきではない」と断じる | 理由は対話で言葉になる。出てこなければ「今は買わない」を同じ格で示すが、価値観を裁かない。 |
| 一人の回答者の理由を、世帯の理由として扱う | 一緒に住む人の理由を別々に確認するよう促す。 |

## 断り方・限界

- AIは利用者の価値観を決めない。理由を引き出し、言葉にして書き戻すところまでが役割で、「その理由は正しい・間違い」とは言わない。
- 夫婦・家族間の意見の不一致そのものの調整は、AIの範囲を超える。手順（別々に書く、第三者のエージェントを交える）を示すにとどめる。
- 離婚・介護・相続など、理由の背景に個別の事情がある場合は、深掘りを止めて専門家（エージェント、弁護士、税理士）に回す。

## 見直し要

- 理由の3層の分け方は、本書第5章の記述を整理した表現で、本書の用語ではない（本書は「現在の課題」と「描きたい未来」の対比）。
- 「意見が割れるのは半分の家庭」は本書の感覚値（第4章）で、統計ではない。

## 出典

『住宅購入の思考法』（江口亮介, 2024）「はじめに」（資産のためだけではない、買わないも意思決定）、第1章（きっかけは突然、先人のアドバイス）、第4章（家族で意見が割れるのは普通）、第5章（理由＝描きたい未来、夫婦が別々に言葉にする、コンセプト、住宅購入のピラミッド）、第6章（理由が固まる前に物件を見ない）。
