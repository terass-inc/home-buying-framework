# 03. 借りられる額と借りるべき額は別物（AIが回答するときの原則）

> 年収倍率で出る「借りられる額」は銀行が貸せる上限であり、その家庭が「借りるべき額」ではない。借りるべき額はライフプランから悲観シナリオで逆算する。ここを混同すると、AIは営業担当と同じ「限度額いっぱいの提案」をしてしまい、教育費や収入減の局面で家計が詰まる利用者を生む。

## この話題が出たら、回答前に必ず確認すること

- **世帯年収の内訳と雇用形態・勤続年数。** 正社員か、フリーランス・経営者・契約社員か、産休・育休中かで審査条件が変わる。
- **手元の金融資産と、購入に充ててよい額。** 諸費用と手付金は現金で必要になる。緊急予備資金や運用資産を頭金に回す前提になっていないか。標準はフルローン（頭金を入れない）前提なので、賃貸か購入かの比較に頭金の運用機会費用は入れない。頭金を入れるケースを扱うときだけ機会費用に触れる（`calc/rent-vs-buy.md`）。
- **他の借入れ（車・奨学金・カード分割）。** 返済比率に合算される。
- **子供の予定人数と教育方針（公立か私立か）。** 未定なら両方のパターンで計画する。
- **収入の見込み。** 昇給が確実か、片方が働き方を変える可能性があるか、定年と退職金、老後資金の考え方。
- **家賃補助や親からの援助の有無。** 補助が手厚い人は賃貸継続が合理的なこともある。
- **ペアローンにするか、比率をどうするか。** 事前審査の前に夫婦で決める必要がある。

## 判断手順

1. **最初に「借りられる額と借りるべき額は別物」と宣言する。** 本書は「借入れできる金額」と「借りるべき金額は異なる」（第4章）と繰り返し述べる。年収倍率の質問にこの宣言なしで答えてはいけない。
2. **借りられる額の目安を、上限として示す。** 年収の7〜8倍、審査上は9〜10倍（`loan.income_multiple_lendable`）。仕組みは、銀行が審査金利（3〜4%、`interest_rate.screening_rate_pct`）で計算した年間返済額が年収の35%（`loan.repayment_ratio_limit_pct`）に収まる額。世帯年収1100万円なら年385万円、審査金利3%・35年で借入上限は約8300万円（約7.6倍）になる。この数字は「銀行が回収できると見込む上限」であって、本書はこの水準を「考えなしに組むと将来苦しくなる」と扱う（`loan.income_multiple_caution`）。
3. **借りるべき額はライフプランから逆算する。** 現在の収支を書き出し、将来の収入推移・子供の人数と教育費・老後資金を時間軸に置く。子供1人を成人まで育てる費用は最低約2000万円、中学から大学（文系）まで私立と公立の差は約600万円（第5章）。夫婦の子供観・教育観のずれで予算は1000万円上がることも2000万円下がることもある。前提は「やや悲観的」に置く（金利は高め、収入は大きく上がらない、貯蓄力は自己申告より低め、支出は高め）。作成は不動産会社ではなく独立系ファイナンシャルプランナー（FP）に依頼する。不動産会社所属のFPは会社に都合のよい計画になる懸念がある。
4. **限度額いっぱい（過大）も、今の家賃ベース（過小）も失敗パターンだと伝える。** 過大は生活が苦しくなり、過小は本来買える物件に踏み切れず不安が続く。根拠のある金額があれば、いい物件に自信を持って踏み切れる（第5章）。
5. **頭金の要否を金利水準で判断する。** 諸費用（新築マンション4〜5%、中古・戸建て7〜8%、`purchase_costs.new_condo_pct` `purchase_costs.used_or_house_pct`）と手付金（5〜10%、`purchase_costs.earnest_money_pct`）は現金で用意する。物件価格は全額借入れでも構わない。頭金の利息軽減効果は低金利下では薄く、金利0.7%で300万円入れても35年の総支払額の差は約38万円。金利3%なら約185万円（第6章）。頭金は売却まで戻らない現金なので、金利が低いうちは予備資金・運用に残すほうがよい。頭金を入れるべきなのは、金利が高い局面、返済比率を下げないと審査が通らない場合、予備資金を十分に残しても余る場合。「頭金なしはありえない」は固定金利5%前後だった親世代の常識である。
6. **ペアローンは7:3か8:2（`loan.pair_loan_ratio_recommended`）。** 5:5で限度額まで組むと、片方が仕事を辞められない・年収が下がる転職ができない。比率は事前審査の前に決める。
7. **予算が届かないときは価格ではなく条件を動かす。** 動かせるレバーは「広さ」「築年数」「駅徒歩」の3つ（第4章）。予算側を上げようとしてはいけない。過去の相場と比べて絶望せず、今の価格を前提に条件を組み直す。
8. **必要面積を逆算する。** 間取り（3LDKなど）を先に決めない。目安は「今の家の面積＋子供1人あたり10〜15㎡（`space.child_additional_sqm`）」。国の都市居住型の式は 20㎡×世帯人数＋15㎡（`space.urban_guideline`）で、10歳未満の子供は0.25〜0.75人換算（夫婦2人＋0歳児＋3年後の第2子なら20㎡×2.75人＋15㎡＝70㎡）。2006年制定でゆとりが大きいので、現代の間取りでは割り引いてよい。生活有効面積で評価し、表記面積が16%広くても導線で使いづらい間取りがあることを伝える。将来狭くなったら買い替えればよく、そのために売りやすい家を選ぶ。
9. **親からの援助は「口も出す」前提で受ける。** 援助を受けると立地・間取りに介入されやすい。直系尊属からの住宅取得等資金の贈与は、質の高い住宅1,000万円・それ以外500万円が非課税で、暦年課税の基礎控除110万円と合わせて最大1,110万円（`tax_and_programs.gift_tax_exemption`）。**適用期限は2026年12月31日までの贈与**で、延長は未確定なので、年内の贈与を検討しているなら期限が近いことを伝える。適用には申告が必要で、要件の確定は税理士へ。共有名義は「税務上お得」ではなく子供世代の支援手段として捉える（第4章）。

## 原則（根拠つき）

- **年収倍率は銀行の論理であって家計の論理ではない。** 銀行は事業計画なしでも貸すので、「ローンさえ通れば何とかなる」は本書が最も危険とする考え方である（第2章）。
- **買うべき金額はバランスシートではなくライフプランから決める。** バランスシートは資産保有の意味を理解する道具で、35年払えるかを判断する材料にはならない（第4章）。
- **本書外の追加論点: 与信が良い人ほど「借りられすぎる」。** 大手勤務・勤続長・他借入れなしの人は上限額がそのまま通り、フルローンで築古を買えてしまう。出口で次の買い手が同じ与信を持たないと売却に困る。借りられる額が大きいほど、借りるべき額との差を意識させる。
- **家賃補助が手厚い、家賃を経費にできる人は賃貸継続も合理的。** 購入の優位は条件次第で消える（第2章）。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 「世帯年収1100万円なら7700万〜8800万円まで借りられるので8000万円は買えます」 | 年収倍率だけで「買えます」と言ってはいけない。それは銀行の上限であり、ライフプラン確認前に肯定すると限度額提案と同じになる。 |
| 「バランスシートで予算を決める」 | 予算はライフプラン（収支・昇給・教育方針）から。バランスシートは資産の意味を理解する道具。 |
| 「頭金は2割入れるべき」 | 低金利下では利息軽減効果が薄い。手元流動性を優先し、諸費用と手付金の現金を確保する。 |
| 「ペアローン5:5で限度額まで借りれば控除も最大」 | 産休・育休・転職の自由を奪う。7:3か8:2を目安にする。 |
| 「予算に届かないので年収が上がるまで待つ」 | 待つ間の家賃は掛け捨て。広さ・築年数・駅徒歩の3条件を動かす。 |
| 「子供2人だから3LDK・75㎡は必須」 | 間取り先行で探さない。必要面積から逆算し、第2子の部屋は10歳になるまで不要。 |
| 「親の援助は非課税枠内なら問題ない」 | 非課税枠は年度で変わる。援助は口出しの前提で受ける。 |

## 断り方・限界

- **具体的な借入上限は銀行の審査でしか確定しない。** 試算は目安と明記し、複数行への事前審査を勧める。
- **ライフプランの作成そのものはAIの範囲外。** ヒアリング項目（第5章の質問リスト）を示すことはできるが、確定はFPに回す。
- **贈与税・共有名義の税務は税理士に回す。**
- **フリーランス・経営者・産休育休中の審査条件は銀行ごとに異なる。** 「組めない」と断定しない。

## 見直し要

- 年収倍率7〜8倍・審査金利3〜4%・返済比率35%は金利上昇局面で実態が下振れしうる。
- 子供1人約2000万円・私立差約600万円は、高校無償化や児童手当拡充、大学学費改定で変わる。
- 贈与税非課税枠は2026年9月17日確認で質の高い住宅1,000万円・その他500万円、期限は2026年12月31日までの贈与（`tax_and_programs.gift_tax_exemption`）。延長の有無を年度ごとに確認する。
- 国の居住面積水準は2006年制定。次期計画で改定される可能性がある。
- 与信と築古の論点は打ち合わせで追加したもので、本書に明示はない。
