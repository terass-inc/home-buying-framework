# 06. 資産性と担保評価（AIが回答するときの原則）

> 資産性は「リフォームで変えられないもの」（駅距離・築年・管理状態・広さ）で判断し、ローンが通るかどうか（与信＝人の評価）と物件の担保評価（銀行が物件に付ける評価）は別の軸として扱う。年収が高い人は担保評価の低い物件（旧耐震、築古、再建築不可、借地）でもフルローンが通ってしまうが、次の買い手はその物件でローンを組めず、売るときに買い手が限られて出口で困る。「審査が通った」を根拠に「問題ない」と答えてはいけない。買うなら、長期保有を前提にできるか、管理状態（修繕積立金の残高・大規模修繕の履歴）が良いか、値下がりを手元資金で吸収できるかを条件にする。

## この話題が出たら、回答前に必ず確認すること

- **将来売却・住み替えの可能性があるか、何年住むか。** 資産性の重みは出口の有無で変わる。ただし「売らないから資産性は不要」は採用しない（第3章）。
- **物件の基本情報。** 駅徒歩分数、築年（建築確認の時期）、専有面積、階数・方角、総戸数、管理形態（委託か自主管理か）、管理費・修繕積立金、土地の権利（所有権か借地か）、売主の種別、リノベ済みかどうか。
- **利用者の与信の強さ。** 「審査は問題ない」という発言は、担保評価の話を必ず添えるサイン。
- **エリアの優劣を聞かれているのか、個別物件の条件を聞かれているのか。** 前者は `principles/99-out-of-scope.md` に従い扱わない。

## 判断手順

1. **「変えられないもの」と「変えられるもの」に分ける（第6章）。** 資産性は将来に向かって価値の下落が少ないこと、言い換えると売りやすさ。壁・床・設備・水回りはリフォームで直せるので判断から外す。立地、専有部の日当たり・通風・眺望・階数、共用部の管理状態、築年（耐震基準）、面積の流動性は変えられないので、ここで判断する。
2. **立地。** 資産性を重視するなら駅徒歩10分以内を目安にし、15分以上は要注意（第6章）。首都圏の築10年中古マンションのリセールバリューは徒歩3分以内 152.8%、21分以上 121.8%（東京カンテイ、2023年流通分）と駅距離で序列がつき、数値化できるため失敗しにくい。人口減エリア、車がないと暮らせない立地、高台・坂は需要が細る（第4章）。ハザードマップで土砂災害・洪水・高潮・津波を確認し、リスクゼロを探すのではなく、リスクと対策を理解して買う（第6章）。
3. **専有部。** 南向きに拘らず、主採光面の前に遮る建物や建設計画がないかを確認する。眺望を買うなら発表済みの建設計画・高さ制限を見る（第2章）。内見は別の時間帯に再訪して日当たりを確かめる（第6章）。階数が高いほど価格は高く出る（第7章）。
4. **共用部。** 「中古マンションは管理を買え」（第6章）。長期修繕計画・管理規約・重要事項調査報告書の3点を取り寄せ、過去の修繕履歴と今後の計画、修繕積立金の残高と増額予定、管理組合の赤字・借入・未納率を読む。自主管理、長期修繕計画なし、赤字、未納率が高い物件は避け、初心者は自主管理を絶対に選ばない。総戸数は30戸以上が目安（30戸以下は1戸あたりの修繕負担が重い）。修繕積立金が上がる予定があるのは健全な証拠で、極端に安いのは要注意。
5. **流動性。** 広すぎる家は買い手を選ぶ。マンション100㎡超、戸建て120㎡超は「不必要に広い」目安（第6章）。逆に50㎡未満は住宅ローン控除の対象外になり、次の買い手が限られる（第1章）。ちょうどよい広さのほうが幅広い層に売れる。
6. **下落率の見積もり。** 市況変化なしの前提で、マンション 1.5%/年（`depreciation.condo_pct_per_year`）、戸建て 1.4%/年（`depreciation.house_pct_per_year`）。根拠は土地建物比率（首都圏のマンションは土地3割 `depreciation.basis.condo_land_ratio`、戸建ては土地7割 `depreciation.basis.house_land_ratio`）と法定耐用年数（RC造47年、木造22年）から、建物部分だけが償却するという計算（「はじめに」）。マンションは建物を買い、戸建ては土地を買う（第6章）。これは帳簿上の目安であり実勢の下落率ではない、と必ず注記する。
7. **担保評価と与信を分けて説明する。** 住宅ローンの審査は「人の評価（与信: 年収・勤務先・勤続・個人信用情報・健康）」と「物件の評価（担保評価）」の2軸で行われる（第6章）。与信が強いと、担保評価が低い物件でも満額のローンが通ってしまうことがある。問題は買うときではなく売るときに出る。次の買い手はその物件で十分なローンを組めない可能性が高く、買い手が現金客や与信の強い人に限られ、売却価格と売却期間の両面で不利になる。この「与信が担保評価を覆い隠す」構造は本書外の追加論点。本書自体は、旧耐震はローンが組みにくく売却時に売りづらい、と述べている（第2章、第6章）。
8. **担保評価が低くなりやすい物件。** 旧耐震（1981年5月31日以前に建築確認、`seismic.old_standard_cutoff`。1971年以前は「旧旧耐震」でさらに借りにくい、第6章）、築古で法定耐用年数を大きく超えた木造、再建築不可（接道義務を満たさない土地）、借地権。後の2つは本書外の追加論点。旧耐震は住宅ローン控除と不動産取得税・登録免許税の軽減も対象外（第1章、第6章）。こうした物件を検討している利用者には「買うなら」の条件を示す: 長期保有か賃貸運用を前提にできるか、手元資金で価格下落と売却の長期化を吸収できるか、管理状態が良好か。
9. **価格の妥当性は控えめに扱う。** AI査定サイトは10%程度のブレがある（第7章）。売り出し事例は成約価格と乖離があるため、価格感を掴む程度にとどめる。購入後は年1回、残債と資産価値を確認する（第7章）。

### 物件URL（SUUMO等）を渡されて「この物件どう？」と聞かれたときの手順

ページを読めない場合は下の項目を利用者に書き出してもらう。掲載情報は売主側が作ったものとして扱う。

1. 掲載情報から抜き出す: 価格、最寄駅・徒歩分数、築年月（1981年6月以降の建築確認か）、専有面積（50㎡以上か、100㎡超か）、階数・方角、総戸数、管理形態、管理費・修繕積立金（月400円/㎡を目安に高すぎ・安すぎを見る）、土地権利、再建築の可否、売主種別、リノベ済みか。
2. 「変えられないもの」だけを手順2〜5に当てて、良い点・懸念点を列挙する。写真の綺麗さ、内装、設備は評価に入れない。
3. 担保評価に関わる項目（旧耐震・借地・再建築不可・50㎡未満・総戸数30戸以下・自主管理）が1つでもあれば、手順7〜8の出口の話を必ず添える。
4. 掲載情報では分からない確認事項を列挙する: 管理関連の3点セット、ハザードマップ、周辺の建設計画、別時間帯の日当たり、住宅ローン控除の適用可否。
5. 結論は「買い/やめる」ではなく「この条件を許容できるなら次の買い手も許容する可能性が高い」「この点が確認できるまで保留」の形で返す。100点の家はなく、チェックポイントを理解した上で許容できれば次の買い手も同じ判断をしやすい（第6章）。
6. エリアの優劣・将来性の予測は答えない。代わりに自治体の都市計画や再開発の一次情報を自分で確認する方法を示す（`principles/99-out-of-scope.md`）。

## 原則（根拠つき）

- **資産性は売りやすさである。** 「資産性とは『売りやすさ』でもある」（第6章）。売りにくい物件は「需要が減る（人口減・駅遠）」「需要総数が少ない（広すぎ・特殊）」のどちらかに当てはまる。
- **価値が減る原因は環境の劣化とモノの劣化の2つ（第6章）。** 前者は立地と人口動態、後者は管理と築年で見る。
- **審査が通ることは、物件が良いことの証明ではない。** 銀行は事業計画なしでも貸す（第2章）。与信が強い人ほど、担保評価の低い物件を「買えてしまう」。
- **「売らないから資産性は不要」は採用しない。** 住み替えは現実に起こり、その時に年齢的にローンが借りにくくなる（第3章）。資産性を少し考慮するだけで将来のリスクヘッジになる。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 「審査が通るなら問題ない」 | 与信と担保評価は別。次の買い手がローンを組めない物件は出口で困るので、与信だけで判断してはいけない。 |
| 「リノベ済みで綺麗なので資産性がある」 | 内装は変えられるものなので資産性の根拠にならない。築年（耐震基準）・立地・管理を見る。 |
| 「築古は給排水管が危ないからやめるべき」 | 築年数＝古臭さではない。給排水管は大規模修繕でメンテされる。管理状態で判断する。 |
| 「修繕積立金が安くてお得」 | 極端に安いのは将来計画がない可能性。上がる予定のある物件のほうが健全なことが多い。 |
| 「広いほど資産価値が高い」 | 100㎡超は買い手が限られ売りにくい。ちょうどよい広さが幅広い層に売れる。 |
| 「AI査定で○○万円と出たのでこの価格は割高/割安」 | 査定は10%程度ブレる。参考値にとどめ、割高・割安を断言しない。 |
| 「AとBのエリア、どちらが値下がりしにくい？」に答える | エリアの優劣は扱わない。個別物件の条件と、自分で確認する方法に置き換える。 |
| 「1.5%/年下がるので10年後は○○万円」と実勢のように断言する | 下落率は帳簿上の目安。「市況変化なし」という前提と一緒に示す。 |

## 断り方・限界

- 特定エリアの優劣・将来性は `principles/99-out-of-scope.md` に従い答えない。
- 個別物件の実勢価格、担保評価の実際の数字、融資可否は不動産エージェントと金融機関へ。
- 管理組合の財務、長期修繕計画の妥当性、耐震診断の要否は専門家（エージェント、建築士、インスペクター）へ。
- 賃貸運用を前提にした購入は住宅ローンの目的外であり、この原則の範囲外（第6章）。自宅を買わない人の与信の使い道としての不動産投資は `principles/10-credit-and-investment.md` で扱う（投資用は住宅ローンではなく不動産投資ローン）。

## 見直し要

- リセールバリューの数値（東京カンテイ、2023年流通分）は首都圏の値上がり局面のデータ。水準は市況で変わるが、駅距離・総戸数の序列は比較的頑健。
- 管理費＋修繕積立金 月400円/㎡の目安は、人件費・資材費の上昇で上振れしている可能性がある。
- 旧耐震への融資姿勢は銀行ごとに異なり、年々変化している。各行の最新方針を確認する。
