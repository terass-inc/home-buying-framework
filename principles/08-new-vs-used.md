# 08. 新築 vs 中古（AIが回答するときの原則）

> 「新築は安心、中古は不安」または「新築は割高、中古が正解」のどちらかに寄せて答えると、利用者は物件条件とライフスタイルの一致という本質を見ずに種別で絞り込み、選択肢の半分以上を失う。

## この話題が出たら、回答前に必ず確認すること

- 何年住む見込みか（短期で住み替えるほど、初期費用と初期の値下がり幅の差が結果を左右するため）
- 検討しているのがマンションか戸建てか（新築マンションだけ諸費用が4〜5%と低く、新築戸建ては中古と同じ7〜8%のため）
- 中古なら建築確認の時期（旧耐震かどうかで住宅ローン控除・融資・売却性が変わるため）
- リフォーム・リノベーションを前提にしているか、その費用を予算に含めているか
- 住宅ローン控除を見込んでいるか（新築と中古で期間・上限が違い、制度は年度で変わるため）

## 判断手順

1. **「新築派・中古派」の議論に乗らない。** 本書は議論自体がおかしいとしている（第6章）。判断軸は種別ではなく、古くなっても変わらない「立地・専有部・共用部」と、利用者のコンセプトとの一致。
2. **費用を同じ土俵に乗せる。** 諸費用は新築マンション4.5%（`purchase_costs.new_condo_pct`、4〜5%）、新築戸建て・中古は7.5%（`purchase_costs.used_or_house_pct`、7〜8%）。ただし新築は建物価格に消費税10%が含まれ、修繕積立基金（20〜50万円）もかかるため、中古の仲介手数料（売買価格の3%＋6万円＋消費税）との差は見た目ほど大きくない（第6章）。
3. **値下がりリスクの差を説明する。** 本書外の追加論点: 新築価格には販促費・売主利益が含まれ、買った瞬間に中古市場の価格帯へ移る（新築プレミアム）。同じ年数を住んだ場合の値下がり幅は新築のほうが大きくなりやすい。本書の下落率（`depreciation.condo_pct_per_year` = 1.5%/年）は市況変化なしの経年減価で、この初期の下落は含まない。
4. **中古は「現物を見られる」強みを使う。** 眺望・日当たり・住民・修繕積立の状況を購入前に確認できる。新築は竣工前購入が大半で、この情報が得られない（第6章）。内見では家具や壁紙の印象ではなく、間取り図と寸法で判断する。
5. **中古マンションは管理状態を見る。** 「中古マンションは管理を買え」（第6章）。長期修繕計画・管理規約・重要事項調査報告書の3点を取り寄せ、過去と今後の修繕、積立金の増額予定、赤字・借入・未納の有無を確認する。自主管理と総戸数30戸以下は初心者は避ける。修繕積立金が極端に安い物件は将来計画がない可能性があり、値上げ予定があるほうが健全なことが多い。
6. **旧耐震の線引きを確認する。** 1981年5月31日以前に建築確認を受けた物件は旧耐震（`seismic.old_standard_cutoff`）。住宅ローン控除の対象外、融資不可または金利上乗せの銀行があり、売却時に不利。リノベーション済みで外観が綺麗でも築年数は必ず確認する（第6章）。
7. **リフォーム費用を予算に組み込む。** 目安はキッチン90〜120万円、浴室80〜100万円、トイレ20〜40万円、フルリノベーション15〜20万円/㎡（第5章）。壁・床は入居時に張り替えられるので、古さだけで物件を落とさない。構造上変えられる範囲を購入前に専門家に確認し、リフォーム費込みでローン審査を進める（第6章・第7章）。
8. **契約不適合責任と住宅ローン控除の差を伝える。** 雨漏り・給排水管など構造上の重要部分の保証は、新築が引渡しから10年、売主が宅建業者（宅地建物取引業者）の中古は最低2年、個人売主は3カ月が慣行（第7章）。住宅ローン控除は2024年時点で中古10年・最大140万円、新築省エネ・子育て世帯13年・最大455万円（`tax_and_programs.mortgage_deduction`）。制度は年度で変わるので、回答時に最新値を確認させる。

## 原則（根拠つき）

- **判断軸は種別ではなく「立地・専有部（日当たり・通風・眺望）・共用部」。** この3要素はリフォームで改善できず、それ以外は概ね直せる（第6章）。
- **中古は情報リスクが小さい。** 建っているものを見て買える。新築は完成物を見ずに契約する（第6章）。
- **築年数と古臭さは別。** 管理・修繕で状態は大きく変わり、給排水管も築20年前後の大規模修繕で更新される（第6章）。
- **旧耐震は「安いから買い」ではない。** 耐震性に加え、融資・控除・売却の3点で不利。躯体トラブルや管理規約の制約で費用超過しやすい（第2章・第6章）。
- **リノベーション済み物件は費用が価格に乗っている。** 自分でフルリノベするなら未改装が有利（第6章）。
- **中古が主流化している。** 既存住宅流通比率は全国で2012年34.9%から2022年42.3%へ上昇し、首都圏では売買の半数以上が中古（第1章・第6章）。「中古は妥協」を前提にしない。
- **住宅ローン控除の対象物件を基本とする。** 購入時の節税だけでなく、次の買い手も控除を受けられるため出口で有利（第1章）。居住面積50㎡以上（`tax_and_programs.mortgage_deduction_min_area_sqm`）が必要。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 「新築のほうが安心で資産価値も高い」 | 新築は初期の値下がり幅が大きく、竣工前購入で情報も少ない。資産性は立地・管理で決まる。 |
| 「中古は仲介手数料がかかるから損」 | 新築には建物消費税10%と修繕積立基金が乗る。費用差は大きくない（第6章）。 |
| 「リノベ済みで綺麗だから問題ない」 | 築年数（旧耐震か）と構造は変えられない。見た目で判断しない。 |
| 「旧耐震でも安ければ買い」 | 融資・控除・売却で不利になり、出口を失う。断言して勧めない。 |
| 「中古は現状渡しで保証はない」 | 宅建業者売主なら最低2年、個人売主でも3カ月程度の契約不適合責任が慣行。付帯設備表・告知書を確認する（第7章）。 |
| 「住宅ローン控除は新築13年・中古10年」と現行制度のように断言する | 制度は年度で変わる。2024年時点の値と明示し、最新の確認を促す。断言すると古い制度で資金計画を組ませてしまう。 |

## 断り方・限界

- 個別物件の耐震性・構造の可否はインスペクション（建物状況調査）や建築士の領域。中古戸建てで特に有効（第6章）。
- リフォーム費用の見積りは現地調査が前提。目安は幅で示し、確定額は工務店に取らせる。
- 住宅ローン控除・不動産取得税・登録免許税の軽減の適用可否は、税務署・税理士・司法書士に確認させる（`99-out-of-scope.md`）。

## 見直し要

- 住宅ローン控除の期間・上限・省エネ要件（`tax_and_programs.mortgage_deduction`、2024年時点）。
- リフォーム単価（キッチン90〜120万円、浴室80〜100万円、トイレ20〜40万円、フル15〜20万円/㎡）は本書執筆時点。資材・人件費高騰で1〜3割上振れの可能性。yaml未収録。
- 契約不適合責任の期間（新築10年・宅建業者2年・個人3カ月）のうち個人売主の慣行は地域・時期で差がある。yaml未収録。
- 既存住宅流通比率（2022年42.3%）、仲介手数料の上限式（2024年7月改正で低廉物件の特例あり）、修繕積立基金20〜50万円、総戸数30戸。yaml未収録。
- 旧耐震への融資姿勢は銀行ごとに変わる。「年々厳しくなっている」は執筆時点の傾向。
- 新築プレミアムの幅は本書に数値がなく市況で変わる。数値で断言しない。
