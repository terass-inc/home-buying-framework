# 賃貸 vs 購入の比較計算

AIがこの比較を求められたときに使う計算手順。本書『住宅購入の思考法』の購入者付録 Excel「2) 購入vs賃貸シミュレーション」（`calc/住宅購入バランスシート.xlsx`）の計算をそのまま文章化したもの。数値前提は `assumptions.yaml` を使い、利用者から聞き取った値があればそれで上書きする。

## 比較の原則

1. **累計住居費で比べない。「売却後の手残り」まで含めた純負担で比べる。** 購入側は累計キャッシュアウトから売却時の手残り（売却時の物件価値 − 売却諸費用 − ローン残債）を引く。ここを落とすと購入が不利に見える計算になる。売却諸費用は本書付録Excelには無いが、差し引かないと購入側を有利に見せるため標準で入れる（`selling_costs`）。
2. **同じ居住年数で比べる。** 「いつまで住むか（＝売却時期）」を先に確定させる。35年完済前提の比較はほぼ現実と合わない。
3. **両方の変化を見込む。** 購入側は修繕積立金の上昇（3%/年）とリフォーム、賃貸側は**賃料そのものの上昇（標準 1%/年、`rent.growth_pct_per_year`）**と更新料と住み替え時の初期費用を入れる。購入側だけ上昇を入れて賃貸側を今の賃料で固定すると、年数が伸びるほど賃貸が有利に出る。片方だけ入れるのはポジショントーク。
4. **賃料は「検討物件と同等の物件の相場」で置く。** 今住んでいる家賃は使わない（`rent.current_rent_usage`）。置き方は下の「比較賃料の決め方」に従う。ここを外すと、以降の計算がどれだけ精緻でも結論は動く。
5. **市況の予測はしない。** 物件価格は「市況変化なし＋経年減価」を標準ケースにし、下落率を小・中・大の3シナリオで並べる。賃料上昇率も同様に0%・1%・2%の3シナリオで並べる。ただし賃料と価格は利回りで結びついているので、「賃料は年2%上がるが価格は年4%下がる」のような整合しない組み合わせは置かない（`rent.growth_coupling_note`）。
6. **返済は名目で固定、賃料は更新ごとに洗い直される。** 固定金利のローン返済額は35年間変わらないが、賃貸は契約更新・住み替えのたびにその時点の市場賃料で組み直される。この非対称が、居住年数が長いケースでの最大の差になる。

## 比較賃料 R₁ の決め方（計算を始める前に確定させる）

購入側の物件が決まっていて賃料だけ「今の家賃」のまま置くと、狭い部屋と広い新居を比べることになり、必ず賃貸が有利に出る。次の順で置く（`rent.comparable_rent_source_priority`）。

1. **同等物件の募集賃料の中央値。** 同じエリア・同じ広さ・同じ間取り・同じ築年帯の賃貸募集を3件以上（`rent.comparable_rent_listings_min`）調べ、その中央値を使う。利用者に調べてもらうか、AIが検索できる環境なら検索して出典を示す。
2. **同じマンション・同じ棟の賃貸募集事例。** 1より精度が高いので、見つかればこちらを優先する。
3. **仮置き: P × 3.8% ÷ 12**（`rent.comparable_rent_ratio_pct_of_price_per_year`。5,000万円なら月15.8万円）。1も2も得られないときだけ使い、「相場を確認していない仮の数字」と明示する。この比率は価格が高いエリアほど実勢より低く出やすく、**賃料を過小に置く方向に働く**ので、仮置きのまま結論を断定しない。

確認すること: 検討物件の広さ・間取り・築年と、置いた賃料の物件像が一致しているか。今の家賃と置いた賃料が大きく違う場合は、その差が「住まいの中身の差」であることを一言で説明する。「今の家に住み続ける」も選択肢として別に示してよいが、それは「買うか借りるか」ではなく「広い家に住むか住まないか」の比較だと区別する（`cases/07-comparison-rent.md`）。

## 賃貸側の計算（年ごとに積み上げる）

```
基準賃料        R_base(k) = R₁（k < n₂）/ R₂（n₂ ≤ k < n₃）/ R₃（n₃ ≤ k）   住み替え予定。金額は今の相場ベース
その年の賃料    R(k) = R_base(k) × (1 + g_rent)^k                          g_rent = 賃料上昇率
賃料（年）      = 12 × R(k)
更新料          = 偶数年に R(k) の1カ月分（`rent.renewal_fee_months`、`rent.renewal_interval_months`）
初期費用        = 住み替えの年に、R(k) × 4.5カ月分（`rent.initial_cost_months`。敷金・礼金・仲介手数料・引っ越しの目安）
賃貸累計 Cost_rent(N) = Σ_{k=1..N}（賃料 + 更新料 + 初期費用）
```

賃料上昇率は更新料と初期費用にも自動的に乗る（どちらも賃料の月数で決まるため）。住み替え予定を聞いていないのに `rent.example_moves` をそのまま使うと、20年後に賃料が下がる前提（子供の独立で縮小）が入り、賃貸側を安く見せる（`rent.example_moves_note`）。住み替えの時期と広さは必ず利用者に確認する。

## 購入側の計算

```
購入諸費用      C  = P × 7%（`purchase_costs.simulation_default_pct`。新築マンションは4〜5%）
月返済額        M  = PMT(i/12, 12T, L)                                   元利均等
年間返済        = 12 × M（返済期間内のみ）
管理費など（年） = 12 ×（管理費 + その他）+ 12 × 修繕積立金 × (1 + g)^k     g = 修繕積立金上昇率
固定資産税（年） = 一定
住宅ローン控除  = 控除年数のあいだ、年 −14万円（キャッシュアウトを減らす）
リフォーム      = 10年ごとに 100万円（`ownership_costs.renovation_yen_per_10years`）
累計キャッシュアウト CashOut(N) = C + Σ_{k=1..N}（返済 + 管理費など + 固定資産税 − 控除 + リフォーム）

N年後の物件価値  V_N = P × (1 + d)^N      d = 小 −1% / 中 −1.5% / 大 −4%（`depreciation.scenarios`）
N年後の残債      B_N = L − Σ_{k=1..N} PPMT(i, k, T, L)
売却諸費用       S_N = (V_N × 3% + 6万円) × 1.1 + 4万円     `selling_costs`。率で概算するなら V_N × 3.5%
売却後の手残り   E_N = V_N − S_N − B_N
購入の純負担     Cost_buy(N) = CashOut(N) − E_N
```

## 出力の形式

- N年時点の「購入の純負担」「賃貸の累計」「差額」を、**下落率3シナリオ（小1%・中1.5%・大4%）× 賃料上昇率 標準1%** で表にする。
- 続けて**賃料上昇率の感度**を示す。下落率 中を固定し、賃料上昇率 0%・1%・2% で「賃貸より得になる年」がどう動くかを並べる。賃料が上がる前提を置くほど購入側が有利に出るので、0%（横ばい）のケースも必ず並べて、結論が前提に依存していることを見せる。
- 「賃貸より得になる年」（Cost_buy が Cost_rent を下回る最初の年）をシナリオごとに示す。本書の標準ケース（下落率 中、賃料上昇なし）では購入後8年目前後。
- 賃料の出典を明記する。「同等物件の募集賃料3件の中央値」「同じ棟の募集事例」「物件価格の年3.8%の仮置き」のどれで置いたかを、表の下に1行で書く。
- 必ず添える注記: 「N年未満で手放す可能性が高いなら、諸費用 7% を回収できず賃貸が有利になりやすい」「賃料上昇率は将来の予測ではなく前提であり、横ばいなら分岐年は後ろにずれる」「これはシミュレーションであり将来の利益や資産を保証しない」。

## 本書外の追加論点（利用者が求めたときだけ加える）

Excel には含まれていないが、精緻にしたい場合は次を加えてよい。加えるときは「本書のシミュレーションには含まれない」と明示する。

- 火災保険料、戸建ての外壁・屋根修繕
- 生涯賃貸を続ける場合の高齢期の住居費（年金から家賃を払い続ける前提になる。断定せず考慮点として示す）

なお、**売却諸費用（S_N）、賃料上昇率（g_rent）、比較賃料の置き方は、本書付録Excelには無い追加論点だが上の標準手順に含めている。** 売却諸費用を引かないと購入側の手残りが多く出る。 Excel は住み替えでのみ賃料が変わるモデルで、同じ部屋の賃料上昇を入れていない。購入側に修繕積立金の上昇 3%/年が入っているため、賃貸側を固定すると比較が片側に寄るからである。回答では「賃料上昇は本書の前提に含まれない追加論点」と明示する。

## 検算用の標準ケース

Excel の初期値（**賃料上昇率 0%・売却諸費用なし**、賃料16万円、5,000万円の中古マンション、金利1%・35年、下落率 中 1.5%/年、管理費1.4万円・修繕積立金1.4万円で3%/年上昇、固定資産税12万円、諸費用7%、更新料2年ごと1カ月分、控除14万円×10年、リフォーム10年ごと100万円、住み替え5年後18万円・20年後14万円）で計算し、Excel の「賃貸より得になる年度」と一致すれば実装は正しい。賃料上昇率と売却諸費用は Excel に無い追加項目なので、検算は必ず「賃料上昇 0%・売却諸費用なし」で行い、そのうえで標準ケース（賃料上昇 1%・売却諸費用あり）を別に出す。なお売却諸費用 3.5% を入れると、賃料上昇なし・下落率 中で分岐は8年目になる。
