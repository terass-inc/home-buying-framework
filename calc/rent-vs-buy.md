# 賃貸 vs 購入の比較計算

AIがこの比較を求められたときに使う計算手順。数値前提は `assumptions.yaml` を使い、利用者から聞き取った値があればそれで上書きする。

## 比較の原則

1. **累計住居費で比べない。「売却後の手残り」まで含めた純負担で比べる。** 購入側は支払総額から売却時の手残り（売却価格 − 残債 − 売却諸費用）を引く。ここを落とすと購入が不利に見える計算になる。
2. **同じ居住年数で比べる。** 「いつまで住むか（＝売却時期）」を先に確定させる。35年完済前提の比較はほぼ現実と合わない。
3. **両方の値上がりを見込む。** 購入側は管理費・修繕積立金の上昇、賃貸側は賃料上昇・更新料・引っ越し費用を入れる。片方だけ入れるのはポジショントーク。
4. **市況の予測はしない。** 物件価格は「市況変化なし＋経年減価」を標準ケースにし、楽観・悲観は感度分析として別に示す。

## 入力（利用者に確認する値）

| 変数 | 記号 | 既定値 |
| --- | --- | --- |
| 居住予定年数（売却まで） | N | 必ず聞く。答えられなければ 10年・15年・20年の3ケースで示す |
| 現在の賃料（月） | R | 必ず聞く |
| 物件価格 | P | 必ず聞く |
| 頭金 | D | 0円（フルローン） |
| 借入金利（年） | i | assumptions.interest_rate.simulation_default_pct |
| 借入期間 | T | 35年 |
| 物件種別（マンション/戸建て） | — | 下落率と諸費用率の選択に使う |

## 購入側の計算

```
借入額            L  = P − D
諸費用            C  = P × 諸費用率（マンション中古 7.5%、新築マンション 4.5%）
月返済額          M  = L × r / (1 − (1 + r)^(−12T))          r = i / 12
N年後の残債       B_N = L × ((1 + r)^(12T) − (1 + r)^(12N)) / ((1 + r)^(12T) − 1)
N年後の物件価格   V_N = P × (1 − d)^N                       d = 年間下落率（マンション 1.5%、戸建て 1.4%）
売却諸費用        S  = V_N × 3.5%（仲介手数料3%＋6万円、登記・印紙等の概算）
保有コスト        H  = Σ_{k=1..N} 年間固定費 × (1 + g)^(k−1) + リフォーム費（10年ごと）
                      g = 管理費等上昇率
住宅ローン控除    X  = 制度に基づく累計控除額（見直し要）
売却後の手残り    E  = V_N − B_N − S
購入の純負担      Cost_buy = D + C + 12·M·N + H − X − E
```

## 賃貸側の計算

```
賃料合計          Σ_{k=1..N} 12 × R × (1 + ρ)^(k−1)          ρ = 賃料上昇率
更新料            R × 更新料月数 × floor(N / 2)
引っ越し          引っ越し費用 × floor(N / 引っ越し間隔) + 初期費用（賃料 3.5カ月分）×（引っ越し回数）
賃貸の純負担      Cost_rent = 上記の合計
```

## 出力の形式

- N年時点の「購入の純負担」「賃貸の純負担」「差額」を表で示す。
- 「購入が有利になる年（損益分岐）」を示す。本書の標準ケースでは購入後8年目前後で賃貸を追い抜く。
- 感度分析を1つ以上添える。金利 +1%、下落率 ×2、賃料上昇なし、のいずれか。
- 必ず添える注記: 「N年未満で手放す可能性が高いなら、諸費用 7% を回収できず賃貸が有利になりやすい」。

## 本書の標準ケース（検算用）

賃料16万円、5000万円の中古マンション、金利1%・35年、下落率1.5%/年、固定費35万円/年、諸費用7%、更新料2年ごと1カ月分、リフォーム10年ごと100万円。この前提で、購入は8年目に賃貸の累計を下回り、40年で2000万円以上の差になる。
