# 賃貸 vs 購入の比較計算

AIがこの比較を求められたときに使う計算手順。本書『住宅購入の思考法』の購入者付録 Excel「2) 購入vs賃貸シミュレーション」（`calc/住宅購入バランスシート.xlsx`）の計算をそのまま文章化したもの。数値前提は `assumptions.yaml` を使い、利用者から聞き取った値があればそれで上書きする。

## 比較の原則

1. **累計住居費で比べない。「売却後の手残り」まで含めた純負担で比べる。** 購入側は累計キャッシュアウトから売却時の手残り（売却時の物件価値 − ローン残債）を引く。ここを落とすと購入が不利に見える計算になる。
2. **同じ居住年数で比べる。** 「いつまで住むか（＝売却時期）」を先に確定させる。35年完済前提の比較はほぼ現実と合わない。
3. **両方の変化を見込む。** 購入側は修繕積立金の上昇とリフォーム、賃貸側は更新料と住み替え時の初期費用を入れる。片方だけ入れるのはポジショントーク。
4. **市況の予測はしない。** 物件価格は「市況変化なし＋経年減価」を標準ケースにし、下落率を小・中・大の3シナリオで並べる。

## 入力（利用者に確認する値）

| 変数 | 記号 | 既定値（Excelの初期値） |
| --- | --- | --- |

| 現在の賃料（月） | R₁ | 16万円 |
| 住み替え1回目（何年後・その後の賃料） | n₂, R₂ | 5年後・18万円（家族が増えて広くする想定） |

## 賃貸側の計算（年ごとに積み上げる）

```
賃料（年）      = 12 × R      （R は住み替え時点で R₁ → R₂ → R₃ に切り替わる）
更新料          = 偶数年に賃料1カ月分（`rent.renewal_fee_months`、`rent.renewal_interval_months`）
初期費用        = 住み替えの年に、新賃料 × 4.5カ月分（`rent.initial_cost_months`。敷金・礼金・仲介手数料・引っ越しの目安）
賃貸累計 Cost_rent(N) = Σ_{k=1..N}（賃料 + 更新料 + 初期費用）
```

## 購入側の計算

```
購入諸費用      C  = P × 7%（`purchase_costs.simulation_default_pct`。新築マンションは4〜5%）
月返済額        M  = PMT(i/12, 12T, L)                                   元利均等
年間返済        = 12 × M（返済期間内のみ）
管理費など（年） = 12 ×（管理費 + その他）+ 12 × 修繕積立金 × (1 + g)^k     g = 修繕積立金上昇率
固定資産税（年） = 一定
住宅ローン控除  = 控除年数のあいだ、年 −14万円（キャッシュアウトを減らす）
リフォーム      = 10年ごとに 100万円（`ownership_costs.renovation_yen_per_10years`）
累計キャッシュアウト CashOut(N) = C + Σ_{k=1..N}（返済 + 管理費など + 固定資産税 − 控除 + リフォーム）

N年後の物件価値  V_N = P × (1 + d)^N      d = 小 −1% / 中 −1.5% / 大 −4%（`depreciation.scenarios`）
N年後の残債      B_N = L − Σ_{k=1..N} PPMT(i, k, T, L)
売却後の手残り   E_N = V_N − B_N
購入の純負担     Cost_buy(N) = CashOut(N) − E_N
```

## 出力の形式

- N年時点の「購入の純負担」「賃貸の累計」「差額」を、下落率3シナリオで表にする。
- 「賃貸より得になる年」（Cost_buy が Cost_rent を下回る最初の年）をシナリオごとに示す。本書の標準ケース（下落率 中）では購入後8年目前後。
- 必ず添える注記: 「N年未満で手放す可能性が高いなら、諸費用 7% を回収できず賃貸が有利になりやすい」「これはシミュレーションであり将来の利益や資産を保証しない」。

## 本書外の追加論点（利用者が求めたときだけ加える）

Excel には含まれていないが、精緻にしたい場合は次を加えてよい。加えるときは「本書のシミュレーションには含まれない」と明示する。

- 売却時の諸費用（仲介手数料 3% + 6万円、登記・印紙など。物件価格の 3.5% 程度）
- 賃料そのものの上昇率（Excelは住み替えで賃料が変わるモデルで、同じ部屋の家賃上昇は入れていない）
- 火災保険料、戸建ての外壁・屋根修繕

## 検算用の標準ケース

Excel の初期値（賃料16万円、5,000万円の中古マンション、金利1%・35年、下落率 中 1.5%/年、管理費1.4万円・修繕積立金1.4万円で3%/年上昇、固定資産税12万円、諸費用7%、更新料2年ごと1カ月分、控除14万円×10年、リフォーム10年ごと100万円、住み替え5年後18万円・20年後14万円）で計算し、Excel の「賃貸より得になる年度」と一致すれば実装は正しい。
