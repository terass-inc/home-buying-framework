# 住宅購入バランスシート

本書『住宅購入の思考法』第3章の「住宅購入のバランスシート」と、購入者付録 Excel「1) 住宅購入バランスシート」（`calc/住宅購入バランスシート.xlsx`）の文章化。「見えるお金は減るが資産は増える」を利用者に見せるための計算。

## 入力

| 項目 | 既定値（Excelの初期値） |
| --- | --- |
| 貯金 | 400万円 |
| 有価証券 | 100万円 |
| その他資産（車・貴金属など） | 100万円 |
| 既存の借入 | 0円 |
| 物件価格 | 5,000万円 |
| 借入割合 | 100%（フルローンが大半） |
| 購入諸費用 | 物件価格の 7%（`purchase_costs.simulation_default_pct`） |
| 借入期間・金利 | 最長で組む前提（Excel初期値は50年）、1% |
| 年間の物件価値減少率 | −1.5%（`depreciation.condo_pct_per_year`） |
| 見たい時点 | 10年後と、利用者が指定した年（既定20年） |

## 3時点のバランスシート

```
【現在】       資産 = 貯金 + 有価証券 + その他        負債 = 既存借入        純資産 = 資産 − 負債
【購入直後】   現金 = 貯金 − 諸費用 −（物件価格 × (1 − 借入割合)）
              住宅 = 物件価格                        負債 = 物件価格 × 借入割合
【N年後】      現金・有価証券・その他 = 購入直後と同じ（家計の貯蓄は別扱い）
              住宅 = 物件価格 × (1 + d)^N
              負債 = ローン残債（元利均等、N年返済後）
              純資産 = 資産合計 − 残債
```

## 読み方（AIが利用者に伝えること）

- 購入直後、現金は諸費用の分だけ減るが、純資産はほぼ変わらない（現金が住宅という資産に置き換わっただけ）。
- N年後に純資産が増えていれば、ローン返済のペースが物件価値の下落ペースを上回っている。この状態なら「売って次に移る」自由がある。
- 純資産が減っていく物件は、価値の下落が返済を上回っている。資産性が低い、または借入期間が長すぎて元本が減っていない。
- 購入後は年1回、残債と物件価値を確認し「残債 < 物件価値」を保てているかを見る（第7章）。
- 標準ケース（5,000万円・金利1%・年1.5%下落）では、10年後に住宅由来の純資産が数百万円のプラスになる。本文の第3章の例は年1%下落で計算しているので、数値を引くときは前提を添える。

## 注意

このシミュレーションは将来の利益や資産を保証しない（Excelの留意事項）。金利・下落率・諸費用は利用者の実情で上書きする。
