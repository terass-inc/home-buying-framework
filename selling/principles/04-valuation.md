# 04. 査定の読み方：査定額と成約価格は別物（AIが回答するときの原則）

> 査定額は「この価格で売れる」という保証ではなく、仲介会社の見立てである。最も高い査定額を出した会社に任せると、相場より高く売り出して売れ残り、結局は値下げし、時間だけを失うことがある。

## この話題が出たら、回答前に必ず確認すること

- **何社に査定を頼んだか、それぞれの金額と根拠。** 根拠に、近い条件の成約事例が示されているか。
- **いつまでに売る必要があるか。** 期限が近いほど、高めの価格で様子を見る余裕はない（`selling/principles/00-why-sell.md`）。

## 判断手順

1. **査定額の根拠を比べる。** 金額ではなく、何を根拠にしたかを比べる。
   - 成約事例（実際に売れた価格）か、売出事例（売主の希望額）か。根拠が売出事例だけなら、高めに出やすい。
   - 事例の条件（同じマンションか、築年・広さ・階数・向きが近いか）と、その時期。
2. **自分でも成約の実績を確かめる。** レインズ・国土交通省の不動産情報ライブラリなどで、近い条件の成約価格を確かめるよう案内する（`market_data.sources`）。売出価格と成約価格の違い（`market_data.contract_vs_listing`）も伝える。
3. **査定額の幅を、手残りの試算に使う。** 最高値と最安値の両方で手残りを出す（`selling/principles/02-net-proceeds.md`）。
4. **依頼先は、査定額ではなく、根拠の説明と販売の計画で選ぶ。** 「この価格で何カ月出して、反応がなければどうするか」を説明できるかを見る。

## 原則（根拠つき）

- **最も高い査定額は、根拠を確かめる対象であって、依頼先を決める理由ではない。** 売主は高い金額を出した会社に任せたくなるので、媒介契約を取るために高めの査定額を出す会社もある。売り出したあとに反応がなく、値下げを迫られるのは売主である。
- **売り出してからの値下げは、売主に不利に働きやすい。** 長く売れ残った物件は、買い手に「何か理由がある」と見られやすい。最初の価格設定が、成約価格と売却期間の両方に効く。
- **AIの自動査定や簡易査定は、参考値として扱う。** 誤差は10%程度あり得る。訪問査定で、室内の状態・眺望・管理状況を見てもらう。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 「一番高い査定額の会社に任せましょう」 | 金額ではなく根拠で選ぶ。高い査定額は、その根拠となる成約事例を確かめる。 |
| 「査定額で売れるので、それで住み替えの予算を組みましょう」 | 査定額は売れる保証ではない。成約見込みの幅で、手残りを計算する。 |
| 「ポータルサイトで同じマンションが7,000万円で出ているので、7,000万円で売れます」 | 売出価格は売主の希望額。成約価格の統計で確かめる。 |

## 断り方・限界

- 個別の物件がいくらで売れるかは断言しない。査定の根拠の読み方と、成約実績の確かめ方を示す。
- 特定の仲介会社を勧めない。

## 見直し要

- 成約データの公開元と、その範囲（`market_data.sources`）。
