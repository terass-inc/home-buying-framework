# 00. なぜ売るのか・いつまでに売るのか（AIが回答するときの原則）

> 売る理由と期限を先に決める。これを飛ばすと、期限のある人に「時間をかけて高く売りましょう」と勧めたり、急ぐ必要のない人に買取を勧めたりして、手残りを数百万円単位で取りこぼす。

## この話題が出たら、回答前に必ず確認すること

- **なぜ売るのか。** 住み替え・相続・転勤・離婚・資金化など。理由で、使える選択肢（賃貸に出す、売らずに持つ）と税の扱いが変わる。相続した家は、取得時期と取得費を引き継ぐ（`tax_and_programs.capital_gains.inheritance_note`）。
- **いつまでに売る必要があるか。** 新居の引き渡し日、転勤の日、相続税の納付期限など、動かせない日があるか。「できれば年内」と「必ず3月まで」は別物として扱う。
- **ローンの残債と、手元の現預金。** 売却額が残債を下回ったとき、差額を現金で埋められるか。

## 判断手順

1. **期限の有無で分ける。** 期限がない、または余裕があるなら、仲介で相場に近い価格を狙える。期限が近いほど、仲介で売り切れなかったときの手（買取への切り替え、値下げの時期と幅）を最初から決めておく。期限までの月数には、売り出してから買い手が見つかるまでの期間と、売買契約から引き渡しまでの期間の両方が入る。媒介契約の期間の上限（`selling_methods.brokerage_contracts.max_term_months`）は、売れるまでの期間の目安ではない。売れるまでの期間は、レインズの成約までの日数の実績を出典つきで示す（`market_data.sources`）。
2. **売らない選択肢を並べる。** 転勤など戻る可能性があるなら、賃貸に出す・空き家のまま持つも比べる。不利な点も並べる。
   - 住宅ローンは居住目的の融資なので、賃貸に出す前に金融機関に相談するよう促す（`principles/01-exit-first.md`）。
   - 住まなくなった日から3年を経過する年の12月31日を過ぎると、3,000万円特別控除を使えなくなる（`tax_and_programs.capital_gains.not_applicable`）。
   - 借り手がいると、自分で住みたい買い手には売れず、売りたいときに売りにくい。
3. **手残りを出す。** `selling/principles/02-net-proceeds.md` に従い、成約見込み価格から残債・売却諸費用・税金を引く。売る理由が住み替えなら、次の家の資金計画とセットで見る。
4. **売り方を決めるのは最後。** どこに頼むか、いくらで出すかは、①期限と②手残りが決まってから。

## 原則（根拠つき）

- **期限が、売り方と価格を決める。** 仲介は買い手を探す時間がかかるぶん、相場に近い価格を狙える。期限が迫るほど、値下げか買取で時間を買うことになる。期限を聞かずに売り方を勧めると、どちらかの損を見落とす。
- **「売らない」も正しい結論である。** 売却には仲介手数料などの諸費用（`selling_costs.simulation_default_pct`）がかかり、買い直せば購入諸費用もかかる。住み替えの理由が「なんとなく」なら、売らない選択肢も並べる。
- **理由によって、税の特例が使えるかが変わる。** 自分が住んでいた家を売るなら、居住用の3,000万円特別控除（`tax_and_programs.capital_gains.home_sale_special_deduction_man_yen`）の対象になり得る。住まなくなってからの年数や、売る相手（親族など）で使えなくなる。確定は税理士へ回す。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 「高く売るために、時間をかけて売りましょう」（期限を聞かずに） | 期限があるなら、時間をかけること自体ができない。先に期限を聞く。 |
| 「急いでいるなら買取が一番です」 | 買取は早く確実だが、価格は仲介の相場より低くなるのが一般的。期限までに仲介で売れる見込みと比べる。 |
| 「転勤なら売ってしまいましょう」 | 戻る可能性があるなら、賃貸に出す・持ち続けるも比べる。購入から年数が浅いと、諸費用を回収できずに損になりやすい。 |
| 「転勤の間は賃貸に出せば、いつでも売れます」 | 3,000万円特別控除の期限と、借り手がいると売りにくいことを示す。 |

## 断り方・限界

- 相続・離婚では、誰が売れるのか（名義・共有・遺産分割）が先に決まっている必要がある。権利関係の判断は司法書士・弁護士へ回す。
- 税の特例を使えるかの確定は、税理士・税務署へ回す。

## 見直し要

- 居住用の3,000万円特別控除の要件は、税制改正で変わることがある（`tax_and_programs.capital_gains.checked_at`）。
