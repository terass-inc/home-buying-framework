# 06. 売出価格の決め方と見直し（AIが回答するときの原則）

> 売出価格は、成約見込み価格に値引き交渉の幅を乗せて決める。「高めに出して様子を見る」は、期限と見直しの計画がなければ、売れ残りと値下げで時間を失う。

## この話題が出たら、回答前に必ず確認すること

- **成約見込み価格の根拠。** 近い条件の成約事例があるか（`selling/principles/04-valuation.md`）。
- **いつまでに売る必要があるか**（`selling/principles/00-why-sell.md`）。
- **手残りがいくらを下回ると困るか。** 住み替え先の資金計画や、残債を下回らない最低ライン（`selling/principles/02-net-proceeds.md`）。

## 判断手順

1. **成約見込み価格に、値引き交渉の幅を乗せる**（`selling_methods.pricing.listing_formula`）。売出事例の価格から決めない。
2. **ポータルサイトの価格の区切りを確かめる**（`selling_methods.pricing.portal_price_bands_note`）。区切りをわずかに超える価格にすると、検索に出なくなる買い手がいる。
3. **売り出す前に、見直しの計画を決める**（`selling_methods.pricing.review_interval_note`）。いつ、どの反響なら、いくら下げるか。期限がある売却では、期限から逆算する。
4. **反響で原因を分ける**（`selling_methods.pricing.review_signals`）。問い合わせがない、内覧はあるが申込みがない、で打つ手が違う。
5. **下げても、手残りが最低ラインを下回らないか確かめる。** 下回るなら、売らない・賃貸に出す・買取も並べる（`selling/principles/05-broker-or-buyout.md`）。

## 原則（根拠つき）

- **最初の数週間に、最も多くの買い手が見る。** 新着の物件は注目されやすく、相場に合った価格ならこの時期に反響が集まる。高すぎる価格でこの時期を逃すと、値下げしても注目は戻りにくい。
- **値下げは計画どおりに行えば損ではない。** 計画なく小刻みに下げると「まだ下がる」と見られ、交渉で押し込まれやすい。
- **価格の決定権は売主にある。** 仲介会社の提案は根拠を確かめたうえで採る。高すぎる査定額に合わせて出すのも、売り急ぎで安く出すのも、根拠がなければ避ける。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 「まずは高めに出して、反応を見て下げればいいです」 | 期限と見直しの計画がなければ、売れ残りで時間を失う。いつ、いくら下げるかを先に決める。 |
| 「値下げは損なので、粘りましょう」 | 待つ費用（`selling/principles/03-rates-and-market.md`）と、計画的な値下げを比べる。 |
| 「4,980万円のように端数にすると売れます」 | 効くのは端数そのものではなく、検索の区切りに入るかどうか。 |

## 断り方・限界

- 個別物件の適正な売出価格は断言しない。成約事例の確かめ方と、見直しの計画の立て方を示す。

## 見直し要

- ポータルサイトの検索条件の区切り（`selling_methods.checked_at`）。
