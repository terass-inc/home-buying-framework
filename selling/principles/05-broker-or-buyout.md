# 05. 仲介か買取か・媒介契約の選び方（AIが回答するときの原則）

> 仲介と買取は、価格と時間の交換である。媒介契約の3種類も、それぞれに売主の利点と不利な点がある。仲介会社が書いた前提なので、仲介に寄せず、買取と同じ厳しさで比べる。

## この話題が出たら、回答前に必ず確認すること

- **いつまでに売る必要があるか**（`selling/principles/00-why-sell.md`）。
- **近所に知られたくない、内覧に対応できない、室内の傷みが大きいなど、仲介で売りにくい事情があるか。**
- **すでに媒介契約を結んでいるか。** 結んでいるなら、種類と期間、販売状況の報告を受けているか。

## 判断手順

1. **買取の価格を、仲介で売れる見込みと比べる。** 買取価格は相場の7〜8割が目安（`selling_methods.buyout_price_ratio_pct`）。差額と、仲介で売れるまでの保有費用・二重の返済を並べる（`selling_methods.buyout_note`）。
   - 例：仲介で5,000万円の見込みなら、買取は3,500万〜4,000万円。差は1,000万〜1,500万円。買取では仲介手数料がかからないことが多いので、その分（約171.6万円）も差し引いて比べる。
2. **中間の手を示す。** 仲介で期限まで売り出し、売れなければ約束の価格で買い取る買取保証（`selling_methods.buyout_guarantee_note`）。
3. **媒介契約の種類を、利点と不利な点の両方で示す**（`selling_methods.brokerage_contracts`）。
   - 専属専任・専任：1社が責任を持って売る。報告とレインズ登録の義務がある。一方で、その1社が囲い込みをすると、他社の買い手に届かない。
   - 一般：複数社に頼めて、囲い込みが起きにくい。一方で、報告の義務がなく、各社が広告に力を入れにくい。
   - 専属専任・専任の契約期間は最長3カ月（`selling_methods.brokerage_contracts.max_term_months`）。更新するかは、販売状況の報告を見て決める。
4. **囲い込みの確かめ方を伝える**（`selling_methods.enclosure_note`）。レインズの登録証明書を受け取り、取引状況が実態と合っているかを確かめる。

## 原則（根拠つき）

- **買取は「損」ではなく、価格と引き換えに時間と確実さを買う選択である。** 期限が近い、内覧に対応できない、売れ残りの負担が大きい人には合う。
- **仲介は「高く売れる」とは限らない。** 価格設定と販売活動しだいで、売れ残って値下げすることもある。売れるまでの期間は読めない。
- **媒介契約は、査定額ではなく、販売の計画と報告の中身で選ぶ**（`selling/principles/04-valuation.md`）。
- **この前提は仲介会社が作っている。** 仲介に有利な説明に偏らないよう、買取の利点と仲介の不利な点も隠さず示す。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 「買取は安く買い叩かれるので、仲介にしましょう」 | 期限と事情によっては買取が合う。差額と、仲介で売れるまでの費用・期間で比べる。 |
| 「急いでいるなら、すぐ買取にしましょう」 | 期限まで仲介で売る見込みと、買取保証も比べる。複数の買取業者に見積もりを取る。 |
| 「専属専任媒介が一番熱心に売ってくれるので、おすすめです」 | 3種類の利点と不利な点を両方示す。囲い込みの確かめ方も伝える。 |
| 「一般媒介で何社にも頼むほうが早く売れます」 | 各社が力を入れにくく、窓口が増える不利もある。 |

## 断り方・限界

- 特定の仲介会社・買取業者を勧めない。
- 媒介契約の解除や違約金など、個別の契約の判断は、契約書を確かめ、必要なら弁護士・宅地建物取引士に相談するよう促す。

## 見直し要

- 買取価格の目安（`selling_methods.buyout_price_ratio_pct`）と、媒介契約の規定（`selling_methods.checked_at`）。
