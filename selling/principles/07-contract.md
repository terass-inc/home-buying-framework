# 07. 売買契約と引き渡し：告知・契約不適合責任・手付・決済（AIが回答するときの原則）

> 売却は、売買契約を結んでも終わらない。知っている不具合を告げずに売ると、引き渡し後に修補や損害賠償を求められる。買主のローン審査が通るまでは、契約も確定しない。

## この話題が出たら、回答前に必ず確認すること

- **知っている不具合や、過去の出来事があるか。** 雨漏り・シロアリ・設備の故障・事件事故・近隣とのトラブルなど。
- **買主は誰か。** 個人か、買取業者か。契約不適合責任の扱いが変わる。
- **残債が売却額を上回らないか。** 上回るなら、引き渡しの日までに差額の現金が要る。
- **住み替え先の日程。** 買主のローン特約の期限と、引き渡しの日。

## 判断手順

1. **不具合は、告知書と付帯設備表に書く**（`selling_methods.contract.disclosure_note`）。「言わなければ分からない」とは答えない。
2. **契約不適合責任の特約を確かめる**（`selling_methods.contract.defect_liability_note`）。期間と範囲、免責の有無。
3. **売る前の建物状況調査（インスペクション）を選択肢に入れる**（`selling_methods.contract.inspection_note`）。
4. **手付と解除のルールを説明する**（`selling_methods.contract.earnest_money_note`）。買主のローン特約の期限も示す（`selling_methods.contract.loan_contingency_note`）。
5. **引き渡しの日に行うことを並べる**（`selling_methods.contract.settlement_items`）。ローンの一括返済と抵当権の抹消、日割り精算、残債が売却額を上回るときの差額の現金。

## 原則（根拠つき）

- **告知は、売主を守るためでもある。** 書いておいた不具合は、契約不適合責任を問われにくい。隠したものは、免責の特約があっても責任を問われ得る。
- **契約から引き渡しまでの日程は、住み替えの資金計画と一体で組む。** ローン特約の期限まで契約は確定しない。新居の契約や仮住まいの予定は、これを前提に組む（`selling/principles/01-trade-up.md`）。
- **手付金を受け取ったら、売主も自由には解除できない。** 解除するには倍額を返す必要がある。別の買い手が高い金額を出しても、安易に乗り換えられない。

## よくある誤解と、AIが言ってはいけないこと

| 誤解・誤答 | 正しい考え方 |
| --- | --- |
| 「小さな雨漏りなら、言わなくても大丈夫です」 | 知っている不具合は告知書に書く。隠すと引き渡し後に責任を問われる。 |
| 「中古なので、売ったあとは何も責任はありません」 | 契約不適合責任がある。期間と範囲は特約で決まるので、契約前に確かめる。 |
| 「契約が済んだので、新居の手続きを進めましょう」 | 買主のローン特約の期限までは白紙解除があり得る。 |

## 断り方・限界

- 個別の契約条項の有効性や、紛争になった場合の判断は、弁護士に相談するよう促す。
- 登記は司法書士、税の申告は税理士・税務署に回す。売却した翌年に確定申告が要る場合があることは伝える。

## 見直し要

- 契約不適合責任の実務と、建物状況調査の制度（`selling_methods.checked_at`）。
