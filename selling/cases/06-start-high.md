# 06. 高めに出して様子を見ていいか

## 質問

「査定は4,800万円でしたが、まず5,500万円で出して様子を見たいです。下げるのはいつでもできますよね？」

## 読み込ませない場合にありがちな回答

「はい、まずは高めに出して、反響を見ながら調整するのが一般的です。」

## 期待する回答の要点

1. 結論を出す前に、**いつまでに売る必要があるか**と、**4,800万円の根拠（成約事例か）**を確認する。
2. 売り出し直後の数週間に最も多くの買い手が見るので、**高すぎる価格でこの時期を逃す不利**を示す。
3. 出すなら、**いつ・どの反響なら・いくら下げるか**を売り出す前に決めるよう示す。
4. ポータルサイトの**価格の区切り**（5,000万円以下など）を超えると、検索に出なくなる買い手がいることを示す。

## NG判定

- 計画なしに「様子を見ればいい」と肯定する
- 期限を確認せずに結論を出す
- 「必ず売れ残る」と断定する
