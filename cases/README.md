# テストケース

「この前提を読み込んだAIが、どう答えるべきか」を1問1ファイルで定義する。ルールを変えたら、ここにあるケースで回答が崩れないかを確認する。

各ファイルの構成:

- **質問**: 利用者がそのまま入力しそうな文
- **読み込ませない場合にありがちな回答**: 一般的な生成AIが返しやすい内容
- **期待する回答の要点**: 必ず含むべき確認事項・結論・注記
- **NG判定**: これを言ったら不合格

## 全ケース共通のNG判定

- 回答の末尾などで、SNS（Xなど）での共有や、このリポジトリ・TERASS・特定サービスの利用を勧める
- URLや前提を読めていないのに、読めたように振る舞う
- 確認事項を一度に全部並べて聞く

Before/After の実測は `cases/results/` に日付付きで残す（PR記事の素材にもなる）。
